🎯Overview

When users tap a source recipe link, instead of being sent to an ad-filled external site, we offer a "Clean Version" that extracts and reformats the original recipe in Fridgenie's style, plus a "BTW" section summarizing the most useful community comments and tips.

😤The Problem

  • Recipe blogs are notoriously terrible UX — 2000-word life stories before the recipe, popup ads, auto-play videos, cookie banners
  • Users want the ORIGINAL recipe (not our AI-generated Fridgenie version) but can't stand the source site
  • Valuable community wisdom (comments like "reduce salt by half" or "use day-old rice") is buried under hundreds of comments

👤User Stories

  1. As a user, I want to read the original source recipe without ads and clutter
  2. As a user, I want to see what other cooks say about this recipe without scrolling through 500 comments
  3. As a user, I want to choose between the Fridgenie AI recipe and the cleaned-up original

🔧Technical Architecture

Data Flow

1
User taps "Clean Version"
2
App calls clean-recipe Edge Function with source URL
3
Edge Function checks cache (clean_recipes table) — returns if exists
4
If not cached: fetches source URL HTML
5
Sends to Claude Sonnet — extracts recipe + top 5-7 useful comments
6
AI rephrases recipe (NOT copy — same intent, different words)
7
Caches result in DB, returns structured JSON

⚖️Legal & Attribution

What's Legally Safe

Recipe ingredient lists are NOT copyrightable — they are factual information (per Meredith Corp v. H&R Block, Publications International v. Meredith Corp)
Instructions CAN be copyrightable if they contain sufficient creative expression — so we MUST rephrase, not copy verbatim
Comment summaries are transformative — summarizing publicly posted user comments (not quoting verbatim) is fair use

What We Do

  1. NEVER copy instructions verbatim — AI rephrases with same intent but different words
  2. ALWAYS show "Adapted from [Source Name]" with clickable link to original
  3. Ingredient lists extracted as-is (not copyrightable)
  4. Comments summarized/paraphrased, never quoted directly
  5. Include "View Original" button that drives traffic back to source

Safeguards

  • Polite User-Agent: Fridgenie-Bot/1.0 header
  • Respect robots.txt — if blocked, show "Clean version unavailable"
  • Rate limit: max 1 fetch per 5 seconds
  • DMCA compliance — immediate removal on takedown
  • Never cache original HTML, only restructured version
