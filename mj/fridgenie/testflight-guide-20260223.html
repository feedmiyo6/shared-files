1 Bundle ID + Signing (Xcode)번들 ID + 서명 (Xcode)

  1. Open Terminal and run: 
    cd ~/Projects/fridgenie/ios
open Runner.xcworkspace
  2. In Xcode, click Runner in the left sidebar (blue project icon at the top)
  3. Click the Runner target → Signing & Capabilities tab
  4. Check ✅ "Automatically manage signing"
  5. Team → Select your Apple Developer account from dropdown
  6. Bundle Identifier → Should be com.fridgenie.fridgenie
    If taken, use something like com.yourname.fridgenie
  7. Green checkmark ✅ next to "Signing Certificate" = you're good!
  1. 터미널 열고 실행: 
    cd ~/Projects/fridgenie/ios
open Runner.xcworkspace
  2. Xcode에서 왼쪽 사이드바의 Runner 클릭 (파란색 프로젝트 아이콘)
  3. Runner 타겟 → Signing & Capabilities 탭 클릭
  4. ✅ "Automatically manage signing" 체크
  5. Team → Apple Developer 계정 선택
  6. Bundle Identifier → com.fridgenie.fridgenie
    이미 사용 중이면 com.yourname.fridgenie로 변경
  7. "Signing Certificate" 옆에 초록 체크 ✅ 나오면 완료!

3 Build & Upload빌드 & 업로드

Terminal — Build the release

터미널 — 릴리즈 빌드

cd ~/Projects/fridgenie

# Clean build
flutter clean
flutter pub get

# Build iOS release with obfuscation
flutter build ios --release --obfuscate --split-debug-info=./debug-info/ios

Xcode — Archive & Upload

  1. Open ios/Runner.xcworkspace if not already open
  2. At the top bar, select: Runner → Any iOS Device (arm64)
    (NOT a simulator — must say "Any iOS Device")
  3. Menu → Product → Archive
    ☕ This takes 3-5 minutes
  4. When done, the Organizer window opens automatically
  5. Click Distribute App
  6. Select App Store Connect → Upload
  7. Click through the options (defaults are fine)
  8. Click Upload
  9. Wait 5-10 min for Apple to process ⏳

Xcode — Archive & 업로드

  1. ios/Runner.xcworkspace 열기
  2. 상단 바에서: Runner → Any iOS Device (arm64) 선택
    (시뮬레이터 아님 — "Any iOS Device"여야 함)
  3. 메뉴 → Product → Archive
    ☕ 3-5분 소요
  4. 완료되면 Organizer 창이 자동으로 열림
  5. Distribute App 클릭
  6. App Store Connect → Upload 선택
  7. 옵션들은 기본값 그대로 → 다음 클릭
  8. Upload 클릭
  9. Apple 처리 대기 5-10분 ⏳
⚠️ Important: Keep the debug-info/ folder! You need it to symbolicate crash reports later.중요: debug-info/ 폴더 보관! 나중에 크래시 리포트 분석에 필요함.

4 TestFlight SetupTestFlight 설정

  1. Go to App Store Connect → Your App → TestFlight tab
  2. After processing, your build appears under iOS Builds
  3. If it says "Missing Compliance" — click it:
    • "Does this app use encryption?" → No
  4. Internal Testing:
    • Click Internal Testing → + → Create group (e.g. "Team")
    • Add yourself (and Lucy if she wants to test!)
    • They get an email invite
  5. Install on your iPhone:
    • Download TestFlight app from App Store
    • Open the invite email on your phone
    • Tap Accept → Install
  1. App Store Connect → 앱 → TestFlight 탭
  2. 처리 완료 후 iOS Builds에 빌드 표시됨
  3. "Missing Compliance" 표시되면 클릭:
    • "Does this app use encryption?" → No
  4. Internal Testing:
    • Internal Testing → + → 그룹 생성 (예: "Team")
    • 본인 추가 (Lucy도 테스트하고 싶으면 추가!)
    • 이메일 초대 발송됨
  5. 아이폰에 설치:
    • App Store에서 TestFlight 앱 다운로드
    • 폰에서 초대 이메일 열기
    • Accept → Install 탭

🔧 Troubleshooting문제 해결

"No signing certificate" in Xcode
→ Go to Xcode → Settings → Accounts → your Apple ID → Download Manual Profiles

Archive is grayed out
→ Make sure you selected "Any iOS Device (arm64)" at the top, NOT a simulator

Upload fails with "Invalid binary"
→ Run flutter clean and rebuild. Make sure Bundle ID matches App Store Connect.

"Missing Compliance" won't go away
→ In App Store Connect → TestFlight → click the build number → Export Compliance → answer No

Build not appearing in TestFlight
→ Wait 10-15 min after upload. Check your email — Apple sends a notification when processing completes (or if there's an error).

Xcode에서 "No signing certificate"
→ Xcode → Settings → Accounts → Apple ID → Download Manual Profiles

Archive 메뉴 비활성화
→ 상단에서 "Any iOS Device (arm64)" 선택했는지 확인 (시뮬레이터 아님)

"Invalid binary" 업로드 실패
→ flutter clean 후 재빌드. Bundle ID가 App Store Connect와 일치하는지 확인.

"Missing Compliance" 해결 안 됨
→ App Store Connect → TestFlight → 빌드 번호 클릭 → Export Compliance → No 선택

TestFlight에 빌드 안 보임
→ 업로드 후 10-15분 대기. 이메일 확인 — Apple이 처리 완료/오류 알림 보냄.
