♿ 3. Accessibility (Apple Takes This Seriously)접근성 (Apple이 진지하게 여김)

🎨Color & Visual Accessibility색상 & 시각 접근성TOTORO ELISSA
⚠️Color contrast ratio — All text must meet WCAG 2.1 AA: 4.5:1 for normal text, 3:1 for large text. Our Ghibli cream backgrounds may be borderline with light text. Need to audit.색상 대비율 — 모든 텍스트는 WCAG 2.1 AA 충족 필요: 일반 텍스트 4.5:1, 큰 텍스트 3:1. Ghibli 크림 배경이 밝은 텍스트와 경계선일 수 있음. 감사 필요.
⚠️Don't rely on color alone — Difficulty indicators (easy/medium/hard) use green/yellow/red. Color blind users can't distinguish these. Add text labels or icons alongside colors.색상만 의존하지 않기 — 난이도 표시 (쉬움/보통/어려움)가 녹색/노란색/빨간색 사용. 색맹 사용자 구별 불가. 색상 옆에 텍스트 라벨 또는 아이콘 추가.
⚠️Expiry traffic light — Red/yellow/green for pantry items. Same issue. Need shape or text backup.유통기한 신호등 — 팬트리 항목에 빨강/노랑/녹색. 같은 문제. 모양 또는 텍스트 백업 필요.

VoiceOver & Screen Reader SupportVoiceOver & 스크린 리더 지원

❌0 Semantics widgets found — Flutter needs explicit Semantics() wrappers for VoiceOver to work properly. Critical screens (home, recipe detail, pantry) need semantic labels. Won't cause rejection for v1 but Apple WILL flag it in future updates.Semantics 위젯 0개 발견 — Flutter에서 VoiceOver가 제대로 작동하려면 명시적 Semantics() 래퍼 필요. v1에서는 거절 원인이 되지 않지만 향후 업데이트에서 Apple이 지적할 수 있음.

Dynamic Type (Text Size)다이나믹 타입 (텍스트 크기)

⚠️Support system text scaling — Users with low vision increase system text size. Flutter generally handles this, but hardcoded fontSize values can break layouts. Test with Settings > Accessibility > Larger Text > max size.시스템 텍스트 크기 조정 지원 — 저시력 사용자가 시스템 텍스트 크기를 증가. Flutter가 일반적으로 처리하지만 하드코딩된 fontSize 값이 레이아웃을 깨뜨릴 수 있음. 설정 > 접근성 > 더 큰 텍스트 > 최대 크기로 테스트.
