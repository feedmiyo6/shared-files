⚠️ Known Issues알려진 문제

  • Clean Recipe extraction fails frequently. Many recipe sites block bot User-Agents (403/406). The function uses "Fridgenie-Bot/1.0" which triggers bot detection. JS-rendered sites (React/Next.js) return empty HTML shells.클린 레시피 추출이 자주 실패합니다. 많은 레시피 사이트가 봇 User-Agent를 차단합니다 (403/406). JS 렌더링 사이트는 빈 HTML을 반환합니다.
  • Only 8 clean recipes cached out of 2,692 sources — 0.3% success rate indicates systemic extraction issues.2,692개 소스 중 8개만 클린 레시피 캐시됨 — 0.3% 성공률은 체계적 추출 문제를 나타냅니다.
  • Fix applied (today): For Today's Pick dishes that have Fridgenie recipes, the Clean Version button is now hidden since the Fridgenie recipe IS the clean version. Main flow still has Clean Version available.수정 적용 (오늘): Fridgenie 레시피가 있는 오늘의 추천 요리에서는 클린 버전 버튼이 숨겨집니다. 메인 플로우에서는 여전히 클린 버전 사용 가능.

Recommended Future Fixes향후 수정 권장사항

  • Use a headless browser (Puppeteer/Playwright) for JS-rendered sites instead of raw fetch()JS 렌더링 사이트에 대해 fetch() 대신 헤드리스 브라우저 사용
