📋 Overview개요

Fridgenie uses Supabase Auth for email verification and password reset. By default, the emails look generic and show Supabase URLs. This guide walks you through making them professional and branded.

Fridgenie는 이메일 인증과 비밀번호 재설정에 Supabase Auth를 사용합니다. 기본 이메일은 일반적이고 Supabase URL을 보여줍니다. 이 가이드는 이메일을 전문적이고 브랜딩된 형태로 만드는 과정을 안내합니다.

What Totoro handled (code): Deep link handling, PKCE auth flow, password reset screen, auth event handler — all done in the app code. 토토로가 처리한 것 (코드): 딥 링크 처리, PKCE 인증 플로우, 비밀번호 재설정 화면, 인증 이벤트 핸들러 — 앱 코드에서 모두 완료.

1️⃣ Configure Redirect URL리다이렉트 URL 설정

1Go to Supabase DashboardSupabase 대시보드로 이동

Open Authentication → URL Configuration

Authentication → URL Configuration 열기

2Add Redirect URL리다이렉트 URL 추가

Under "Redirect URLs", add:

"Redirect URLs" 아래에 추가:

com.fridgenie.app://callback

This tells Supabase to redirect back to the app after email verification / password reset.

이메일 인증/비밀번호 재설정 후 앱으로 다시 리다이렉트하도록 Supabase에 알려줍니다.

Important: If this URL isn't in the allow list, Supabase will silently ignore the redirect and the deep link won't work! 중요: 이 URL이 허용 목록에 없으면 Supabase가 리다이렉트를 무시하고 딥 링크가 작동하지 않습니다!

3️⃣ Custom SMTP with ResendResend로 커스텀 SMTP 설정 Recommended

Why this matters: Supabase free tier only sends 4 emails per hour via built-in SMTP. For production with real users, you NEED custom SMTP or emails will be silently dropped. 왜 중요한가: Supabase 무료 플랜은 내장 SMTP로 시간당 4개의 이메일만 전송합니다. 실제 사용자가 있는 프로덕션에서는 커스텀 SMTP가 필수입니다. 그렇지 않으면 이메일이 조용히 드랍됩니다.
1Sign up for ResendResend 가입

Go to resend.com and create a free account.

resend.com에서 무료 계정 생성.

Free tier: 3,000 emails/month, 100/day — more than enough for launch.

무료 플랜: 월 3,000건, 일 100건 — 런칭에 충분합니다.

2Add & verify your domain도메인 추가 & 인증

In Resend dashboard → Domains → Add fridgenie.app

Resend 대시보드 → Domains → fridgenie.app 추가

They'll give you DNS records (DKIM, SPF) to add at your domain registrar. This ensures emails come from @fridgenie.app and don't land in spam.

도메인 등록기관에 추가할 DNS 레코드(DKIM, SPF)를 제공합니다. 이메일이 @fridgenie.app에서 발송되고 스팸에 안 걸립니다.

3Get SMTP credentialsSMTP 인증정보 가져오기

In Resend → SMTP settings, you'll see:

Resend → SMTP settings에서 확인:

Host: smtp.resend.com Port: 465 Username: resend Password: re_xxxxxxxxxx (your API key)
4Configure in SupabaseSupabase에서 설정

Go to Project Settings → Auth → SMTP Settings

Project Settings → Auth → SMTP Settings 열기

Toggle "Enable Custom SMTP" ON, then fill in:

"Enable Custom SMTP" 활성화 후 입력:

Sender email: hello@fridgenie.app Sender name: Fridgenie Host: smtp.resend.com Port: 465 Username: resend Password: [your Resend API key] Minimum interval: 30 (seconds between emails per user)
After this, all auth emails will come from hello@fridgenie.app with your branded templates. Professional! 🎉 이후 모든 인증 이메일이 hello@fridgenie.app에서 브랜딩된 템플릿으로 발송됩니다. 전문적! 🎉

4️⃣ Testing Checklist테스트 체크리스트

After setting up templates and (optionally) SMTP, test these flows:

템플릿과 (선택사항) SMTP 설정 후 다음 플로우를 테스트:

  • Email signup: Sign up with new email → get branded verification email → tap link → app opens → lands on household setup이메일 가입: 새 이메일로 가입 → 브랜딩된 인증 이메일 수신 → 링크 탭 → 앱 열림 → 가구 설정으로 이동
  • Forgot password: Tap "Forgot password" → enter email → get branded reset email → tap link → app opens → reset password screen → enter new password → success비밀번호 찾기: "비밀번호 찾기" 탭 → 이메일 입력 → 브랜딩된 재설정 이메일 수신 → 링크 탭 → 앱 열림 → 비밀번호 재설정 화면 → 새 비밀번호 입력 → 성공
  • Resend verification: On confirmation screen, tap "Resend" → get another email within a minute인증 재전송: 확인 화면에서 "재전송" 탭 → 1분 내에 또 다른 이메일 수신
  • Apple Sign-In: Still works normally (no email needed)Apple 로그인: 정상 작동 확인 (이메일 불필요)
  • Check spam folder: If using default Supabase SMTP, emails may land in spam. Custom SMTP (Resend) fixes this.스팸 폴더 확인: 기본 Supabase SMTP 사용 시 이메일이 스팸에 갈 수 있습니다. 커스텀 SMTP (Resend)로 해결됩니다.
