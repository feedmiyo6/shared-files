Registers vs Wires — Quiz 레지스터 vs 와이어 — 퀴즈

Q1. What does reg actually mean in Verilog?

  • A) It always creates a hardware flip-flop
  • B) It represents a physical wire connection
  • C) It's a variable that can hold a value in procedural blocks
  • D) It can only be used with clock edges
C — reg simply means a variable usable in procedural blocks (always, initial, etc.). It may synthesize to combinational logic or a flip-flop depending on context. C — reg는 절차적 블록(always, initial 등)에서 사용할 수 있는 변수를 의미합니다. 문맥에 따라 조합 논리 또는 플립플롭으로 합성될 수 있습니다.

Q2. Which SystemVerilog type replaces both wire and reg?

  • A) bit
  • B) logic
  • C) int
  • D) net
B — logic can be used in both continuous and procedural assignments, replacing both wire and reg in most cases. B — logic은 연속 할당과 절차적 할당 모두에서 사용할 수 있어, 대부분의 경우 wire와 reg를 대체합니다.

Q3. When must you still use wire instead of logic?

  • A) For module input ports
  • B) For continuous assignments
  • C) Inside always_comb blocks
  • D) For tri-state or multi-driver nets
D — logic only supports a single driver. Multi-driver nets (like tri-state buses) require wire. D — logic은 단일 드라이버만 지원합니다. 다중 드라이버 넷(트라이스테이트 버스 등)에는 wire가 필요합니다.

Q4. What is the default initial value of a logic variable?

  • A) X (unknown)
  • B) 0
  • C) Z (high-impedance)
  • D) 1
A — logic is a 4-state type that defaults to X. This helps catch uninitialized signals during simulation. A — logic은 4상태 타입으로 X가 기본값입니다. 시뮬레이션에서 초기화되지 않은 신호를 잡는 데 도움이 됩니다.

Q5. What does this code synthesize to?

reg y;
always @(*) begin
    y = a | b;
end
  • A) A D flip-flop
  • B) A latch
  • C) An OR gate (combinational)
  • D) A tri-state buffer
C — Despite using reg, the always @(*) block with complete assignment makes this purely combinational — it's just an OR gate. C — reg를 사용했지만, 완전한 할당이 있는 always @(*) 블록은 순수 조합 논리입니다 — OR 게이트일 뿐입니다.

Q6. Which is a 2-state type?

  • A) logic
  • B) bit
  • C) wire
  • D) reg
B — bit is a 2-state type (0, 1 only). It defaults to 0 and is faster for simulation but won't catch X-propagation bugs. B — bit은 2상태 타입(0, 1만)입니다. 기본값은 0이며 시뮬레이션이 빠르지만 X 전파 버그를 잡지 못합니다.

Q7. Which is ILLEGAL in Verilog?

  • A) input reg [7:0] data
  • B) output reg [7:0] data
  • C) input wire [7:0] data
  • D) output wire [7:0] data
A — Module inputs cannot be reg because they are driven externally. Inputs are always nets (wire). Outputs can be either. A — 모듈 입력은 외부에서 구동되므로 reg가 될 수 없습니다. 입력은 항상 넷(wire)입니다. 출력은 둘 다 가능합니다.

Q8. In SystemVerilog, what determines if hardware is sequential or combinational?

  • A) Whether you use wire or reg
  • B) The variable declaration type
  • C) The port direction (input/output)
  • D) The block type (always_ff vs always_comb)
D — In SystemVerilog, the block type makes the intent clear. always_ff = sequential, always_comb = combinational. The variable type (logic) is the same for both. D — SystemVerilog에서는 블록 타입이 의도를 명확히 합니다. always_ff = 순차, always_comb = 조합. 변수 타입(logic)은 둘 다 동일합니다.

Q9. What happens if you try two assign statements to a logic signal?

  • A) The last assignment wins
  • B) The signals get OR'd together
  • C) Compile error
  • D) Both values resolve to X
C — logic supports only a single driver. Multiple continuous assignments will cause a compile-time error. Use wire for multi-driver nets. C — logic은 단일 드라이버만 지원합니다. 여러 연속 할당은 컴파일 오류를 발생시킵니다. 다중 드라이버 넷에는 wire를 사용하세요.

Q10. Why is bit NOT recommended for RTL design?

  • A) It's too slow for simulation
  • B) It can't represent X/Z, hiding potential bugs
  • C) It's not supported by synthesis tools
  • D) It only works in testbenches
B — bit is 2-state (0 and 1 only). Uninitialized signals default to 0 instead of X, which masks bugs that would otherwise be visible in simulation waveforms. B — bit은 2상태(0과 1만)입니다. 초기화되지 않은 신호가 X 대신 0이 되어, 시뮬레이션 파형에서 보일 버그를 숨깁니다.

Q11. Which declaration is best practice in modern SystemVerilog?

// Option A:
module top(input logic clk, output logic [7:0] data);
// Option B:
module top(input wire clk, output reg [7:0] data);
// Option C:
module top(input clk, output [7:0] data);
// Option D:
module top(input bit clk, output bit [7:0] data);
  • A) Option A
  • B) Option B
  • C) Option C
  • D) Option D
A — Using logic for all ports is the modern SystemVerilog best practice. It's clean, consistent, and avoids the wire/reg confusion entirely. A — 모든 포트에 logic을 사용하는 것이 최신 SystemVerilog 모범 사례입니다. 깔끔하고 일관적이며 wire/reg 혼란을 완전히 피합니다.

Q12. What does Z represent in a 4-state type?

  • A) Zero
  • B) Unknown/uninitialized
  • C) High-impedance (not driven)
  • D) Conflict between drivers
C — Z means high-impedance — the signal is not being actively driven. This is used in tri-state buses where a device can "disconnect" from the bus. C — Z는 하이 임피던스를 의미합니다 — 신호가 능동적으로 구동되지 않는 상태입니다. 장치가 버스에서 "분리"될 수 있는 트라이스테이트 버스에서 사용됩니다.
