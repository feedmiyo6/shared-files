Exercise 1: AXI Write Strobe Decoder

연습 1: AXI 쓰기 스트로브 디코더

Write a module that applies write strobes to update a 32-bit register. The module takes the current register value, new write data, and a 4-bit write strobe, and outputs the merged result.

현재 레지스터 값, 새 쓰기 데이터, 4비트 쓰기 스트로브를 받아 병합된 결과를 출력하는 모듈을 작성하세요.

module wstrb_merge (
    input  logic [31:0] current_val,  // Current register value
    input  logic [31:0] wdata,        // New write data
    input  logic [3:0]  wstrb,        // Write strobes
    output logic [31:0] merged_val    // Result
);

    // TODO: Implement byte-level merge using wstrb
    // For each byte: if wstrb[i]==1, use wdata byte; else keep current

endmodule

💡 Hint: Use a for loop or generate to iterate over each byte. The +: part-select operator is your friend: data[i*8 +: 8] selects 8 bits starting at position i*8.

💡 힌트: for 루프나 generate를 사용하여 각 바이트를 반복합니다. +: 부분 선택 연산자를 사용하세요.

module wstrb_merge (
    input  logic [31:0] current_val,
    input  logic [31:0] wdata,
    input  logic [3:0]  wstrb,
    output logic [31:0] merged_val
);

    always_comb begin
        for (int i = 0; i < 4; i++) begin
            if (wstrb[i])
                merged_val[i*8 +: 8] = wdata[i*8 +: 8];
            else
                merged_val[i*8 +: 8] = current_val[i*8 +: 8];
        end
    end

endmodule

// Testbench
module tb_wstrb;
    logic [31:0] current, wdata, merged;
    logic [3:0]  wstrb;

    wstrb_merge dut (.*);

    initial begin
        current = 32'hAAAAAAAA;
        wdata   = 32'hBBBBBBBB;

        wstrb = 4'b0101; #1;
        $display("WSTRB=0101: %h (expect AABBAAbb)", merged);

        wstrb = 4'b1111; #1;
        $display("WSTRB=1111: %h (expect BBBBBBBB)", merged);

        wstrb = 4'b0000; #1;
        $display("WSTRB=0000: %h (expect AAAAAAAA)", merged);

        wstrb = 4'b1000; #1;
        $display("WSTRB=1000: %h (expect BBAAAAAA)", merged);
    end
endmodule

Exercise 2: AXI-Lite Read-Only Slave

연습 2: AXI-Lite 읽기 전용 슬레이브

Build a read-only AXI-Lite slave that serves 4 hardcoded status registers. It only needs to implement the AR and R channels. Focus on getting the Ready/Valid handshake right.

4개의 하드코딩된 상태 레지스터를 제공하는 읽기 전용 AXI-Lite 슬레이브를 구축하세요. AR과 R 채널만 구현하면 됩니다.

module axi_lite_ro_slave (
    input  logic        ACLK,
    input  logic        ARESETn,
    // Read Address Channel
    input  logic [3:0]  ARADDR,
    input  logic        ARVALID,
    output logic        ARREADY,
    // Read Data Channel
    output logic [31:0] RDATA,
    output logic [1:0]  RRESP,
    output logic        RVALID,
    input  logic        RREADY
);

    // Status registers (hardcoded for now)
    // Reg 0: Version    = 32'h0001_0000
    // Reg 1: Status     = 32'h0000_00FF
    // Reg 2: Error Count = 32'h0000_0042
    // Reg 3: Features   = 32'hDEAD_BEEF

    // TODO: Implement AR/R handshake
    // 1. Accept read address when ARVALID && ARREADY
    // 2. Look up register value
    // 3. Present RDATA + RVALID
    // 4. Wait for RREADY to complete transfer

endmodule

💡 Hint: Use a simple state: when idle, assert ARREADY. On address acceptance, deassert ARREADY, look up the register, and assert RVALID. When RREADY comes, go back to idle. Use ARADDR[3:2] to select the register (word-aligned addresses).

💡 힌트: 간단한 상태를 사용하세요: 유휴 시 ARREADY를 어설션합니다. 주소 수락 후 ARREADY를 해제하고 레지스터를 조회하여 RVALID를 어설션합니다.

module axi_lite_ro_slave (
    input  logic        ACLK,
    input  logic        ARESETn,
    input  logic [3:0]  ARADDR,
    input  logic        ARVALID,
    output logic        ARREADY,
    output logic [31:0] RDATA,
    output logic [1:0]  RRESP,
    output logic        RVALID,
    input  logic        RREADY
);

    // Hardcoded status registers
    logic [31:0] regs [0:3];
    assign regs[0] = 32'h0001_0000; // Version
    assign regs[1] = 32'h0000_00FF; // Status
    assign regs[2] = 32'h0000_0042; // Error Count
    assign regs[3] = 32'hDEAD_BEEF; // Features

    // State: reading or idle
    logic rd_active;

    assign ARREADY = !rd_active;
    assign RVALID  = rd_active;
    assign RRESP   = 2'b00; // Always OKAY

    always_ff @(posedge ACLK or negedge ARESETn) begin
        if (!ARESETn) begin
            rd_active <= 1'b0;
            RDATA     <= 32'h0;
        end
        else if (!rd_active && ARVALID) begin
            // Accept address, look up register
            rd_active <= 1'b1;
            RDATA     <= regs[ARADDR[3:2]];
        end
        else if (rd_active && RREADY) begin
            // Read data accepted, go idle
            rd_active <= 1'b0;
        end
    end

endmodule

Exercise 3: AXI Burst Address Calculator

연습 3: AXI 버스트 주소 계산기

Write a combinational module that calculates the next address in an AXI INCR burst. Given the current address and the transfer size (AWSIZE), output the next beat's address.

현재 주소와 전송 크기(AWSIZE)가 주어지면 다음 비트의 주소를 출력하는 조합 모듈을 작성하세요.

module axi_incr_addr (
    input  logic [31:0] current_addr,
    input  logic [2:0]  axsize,       // 2^axsize = bytes per beat
    output logic [31:0] next_addr
);

    // TODO: Calculate next address
    // next_addr = current_addr + (1 << axsize)

endmodule

💡 Hint: The increment is simply 2^AXSIZE bytes. Use the shift operator: 1 << axsize. For AXSIZE=0 (1 byte), increment by 1. For AXSIZE=2 (4 bytes/32-bit), increment by 4.

💡 힌트: 증분은 단순히 2^AXSIZE 바이트입니다. 시프트 연산자를 사용하세요.

module axi_incr_addr (
    input  logic [31:0] current_addr,
    input  logic [2:0]  axsize,
    output logic [31:0] next_addr
);

    assign next_addr = current_addr + (32'd1 << axsize);

endmodule

// Testbench
module tb_incr_addr;
    logic [31:0] addr, next;
    logic [2:0]  size;

    axi_incr_addr dut (
        .current_addr(addr),
        .axsize(size),
        .next_addr(next)
    );

    initial begin
        // 1 byte per beat (AXSIZE=0)
        addr = 32'h1000; size = 3'd0; #1;
        $display("1-byte: 0x%h → 0x%h (expect 0x1001)", addr, next);

        // 4 bytes per beat (AXSIZE=2)
        addr = 32'h1000; size = 3'd2; #1;
        $display("4-byte: 0x%h → 0x%h (expect 0x1004)", addr, next);

        // 8 bytes per beat (AXSIZE=3)
        addr = 32'h2000; size = 3'd3; #1;
        $display("8-byte: 0x%h → 0x%h (expect 0x2008)", addr, next);

        // Chain: simulate 4-beat burst at 4 bytes each
        addr = 32'h3000; size = 3'd2;
        for (int beat = 0; beat < 4; beat++) begin
            #1;
            $display("Beat %0d: addr=0x%h", beat, addr);
            addr = next;
        end
    end
endmodule

Exercise 4: AXI-Lite Slave with Read/Write (Challenge!)

연습 4: 읽기/쓰기를 갖춘 AXI-Lite 슬레이브 (도전!)

Combine everything: build a full AXI-Lite slave with 4 read/write registers including WSTRB support. This is the real-world pattern you'll see in every IP block.

모든 것을 결합하세요: WSTRB 지원을 포함하여 4개의 읽기/쓰기 레지스터를 갖춘 전체 AXI-Lite 슬레이브를 구축하세요.

📋 Requirements

📋 요구사항

  • 4 registers at addresses 0x0, 0x4, 0x8, 0xC
  • 주소 0x0, 0x4, 0x8, 0xC에 4개의 레지스터
  • All 5 AXI-Lite channels (AW, W, B, AR, R)
  • 모든 5개 AXI-Lite 채널 (AW, W, B, AR, R)
  • WSTRB byte-level write control
  • WSTRB 바이트 수준 쓰기 제어
  • Active-low async reset
  • 액티브 로우 비동기 리셋
  • BRESP and RRESP always return OKAY
  • BRESP와 RRESP는 항상 OKAY 반환

💡 Hint: Reference the AXI-Lite slave code from the lesson! The key challenge is handling AW and W channels independently — the write address and write data can arrive in any order. Track both with aw_done and w_done flags, and only send BVALID when both are received.

💡 힌트: 레슨의 AXI-Lite 슬레이브 코드를 참조하세요! 핵심은 AW와 W 채널을 독립적으로 처리하는 것입니다.

// Full AXI-Lite R/W slave — see the lesson code for the
// complete implementation! The pattern is:
//
// 1. WRITE: Track aw_done and w_done independently
//    - AWREADY = !aw_done (accept address when available)
//    - WREADY  = !w_done  (accept data when available)
//    - When WVALID && WREADY: apply WSTRB merge to reg_file
//    - BVALID = aw_done && w_done
//    - On BVALID && BREADY: clear both flags
//
// 2. READ: Single rd_valid flag
//    - ARREADY = !rd_valid
//    - On ARVALID && ARREADY: capture RDATA from reg_file
//    - RVALID = rd_valid
//    - On RVALID && RREADY: clear rd_valid
//

⚠️ Common Mistakes to Avoid

  • Forgetting WLAST: In full AXI, the slave needs WLAST to know when a burst ends. AXI-Lite doesn't have bursts, so no WLAST needed.
  • WLAST 잊기: 전체 AXI에서 슬레이브는 버스트가 끝나는 시점을 알기 위해 WLAST가 필요합니다.
  • Combinational READY: Don't make AWREADY depend on AWVALID combinationally — this creates a deadlock risk.
  • 조합적 READY: AWREADY가 AWVALID에 조합적으로 의존하지 않도록 하세요 — 교착 상태 위험이 있습니다.
  • Missing reset: All state and output registers must be reset. Unreset RVALID can cause phantom reads.
  • 누락된 리셋: 모든 상태 및 출력 레지스터는 리셋되어야 합니다.
