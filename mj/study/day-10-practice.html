Exercise 1: Vending Machine FSM Medium

📋 Specification

Design a vending machine that accepts 5¢ and 10¢ coins. Item costs 15¢. The machine should:

5¢와 10¢ 동전을 받는 자판기를 설계하세요. 물건 가격은 15¢입니다:

  • Accept coins and track total
  • Dispense when total ≥ 15¢
  • Give change if overpaid (e.g., 10¢ + 10¢ = 5¢ change)
  • Return to idle after dispensing
  • 동전을 받고 총액 추적
  • 총액 ≥ 15¢이면 물건 배출
  • 초과 지불 시 거스름돈 (예: 10¢ + 10¢ = 5¢ 거스름돈)
  • 배출 후 대기 상태로 복귀
module vending_machine (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       nickel,    // 5¢ inserted
    input  logic       dime,      // 10¢ inserted
    output logic       dispense,  // item out
    output logic       change     // 5¢ change
);

    // YOUR CODE HERE
    // States: IDLE, FIVE, TEN, DISPENSE
    // Think about: What inputs cause transitions?
    //              When do we dispense + give change?

endmodule

💡 Hints

States represent accumulated money: IDLE(0¢), FIVE(5¢), TEN(10¢). From TEN, a dime means 20¢ → dispense + change. Use Moore outputs for clean design.

상태는 누적된 금액을 나타냅니다: IDLE(0¢), FIVE(5¢), TEN(10¢). TEN에서 dime이면 20¢ → 배출 + 거스름돈. 깔끔한 설계를 위해 Moore 출력 사용.

module vending_machine (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       nickel,
    input  logic       dime,
    output logic       dispense,
    output logic       change
);

    typedef enum logic [2:0] {
        IDLE,          // 0¢
        FIVE,          // 5¢
        TEN,           // 10¢
        DISPENSE,      // exact — no change
        DISPENSE_CHG   // overpaid — return 5¢
    } state_t;

    state_t state, next_state;

    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= IDLE;
        else
            state <= next_state;
    end

    always_comb begin
        next_state = state;
        case (state)
            IDLE: begin
                if (nickel)     next_state = FIVE;
                else if (dime) next_state = TEN;
            end
            FIVE: begin
                if (nickel)     next_state = TEN;
                else if (dime) next_state = DISPENSE;
            end
            TEN: begin
                if (nickel)     next_state = DISPENSE;
                else if (dime) next_state = DISPENSE_CHG;
            end
            DISPENSE:      next_state = IDLE;
            DISPENSE_CHG:  next_state = IDLE;
            default:       next_state = IDLE;
        endcase
    end

    // Moore outputs
    assign dispense = (state == DISPENSE) || (state == DISPENSE_CHG);
    assign change   = (state == DISPENSE_CHG);

endmodule

Exercise 2: Pattern Detector "110" (Moore) Medium

📋 Specification

Build an overlapping Moore sequence detector for pattern 110. The output should assert one cycle after the pattern completes (since Moore outputs are registered).

오버래핑 Moore 시퀀스 디텍터를 패턴 110에 대해 만드세요. Moore 출력은 레지스터링되므로 패턴 완료 한 사이클 후에 출력이 어서트됩니다.

module seq_detect_110_moore (
    input  logic clk,
    input  logic rst_n,
    input  logic din,
    output logic detected
);

    // YOUR CODE HERE
    // Moore needs an extra state: DETECTED
    // States: IDLE, GOT_1, GOT_11, DETECTED
    // Key difference from Mealy: output is part of state!

endmodule

💡 Hints

Moore needs a DETECTED state where detected=1. From DETECTED, check din to handle overlapping: if din=1, go to GOT_1 (potential new match). Compare: Mealy has 3 states, Moore has 4.

Moore는 detected=1인 DETECTED 상태가 필요합니다. DETECTED에서 din을 확인하여 오버래핑 처리: din=1이면 GOT_1로 (새 매치 가능). 비교: Mealy는 3상태, Moore는 4상태.

module seq_detect_110_moore (
    input  logic clk,
    input  logic rst_n,
    input  logic din,
    output logic detected
);

    typedef enum logic [2:0] {
        IDLE,
        GOT_1,
        GOT_11,
        DETECTED   // Moore: output state
    } state_t;

    state_t state, next_state;

    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= IDLE;
        else
            state <= next_state;
    end

    always_comb begin
        next_state = IDLE;
        case (state)
            IDLE:     next_state = din ? GOT_1  : IDLE;
            GOT_1:    next_state = din ? GOT_11 : IDLE;
            GOT_11:   next_state = din ? GOT_11 : DETECTED;
            DETECTED: next_state = din ? GOT_1  : IDLE;
            default:  next_state = IDLE;
        endcase
    end

    // Moore output: depends ONLY on state
    assign detected = (state == DETECTED);

endmodule

Exercise 3: Pedestrian Traffic Light Hard

📋 Specification

Extend the traffic light controller with a pedestrian crossing button:

교통 신호등 컨트롤러에 보행자 횡단 버튼을 추가하세요:

  • Pedestrian button press is remembered (latched) until serviced
  • During GREEN_NS: if pedestrian requested, shorten green to 5 cycles (instead of 10)
  • Add a WALK state (6 cycles) after YELLOW_NS when pedestrian is pending
  • Add a FLASH state (4 cycles) after WALK — warning before EW goes green
  • Clear the pedestrian request after FLASH completes
  • 보행자 버튼 누름은 처리될 때까지 기억됨 (래치)
  • GREEN_NS 중: 보행자 요청 시 초록을 5사이클로 단축 (10 대신)
  • 보행자 대기 중이면 YELLOW_NS 후 WALK 상태 추가 (6 사이클)
  • WALK 후 FLASH 상태 추가 (4 사이클) — EW 초록 전 경고
  • FLASH 완료 후 보행자 요청 클리어
module ped_traffic_light (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       ped_btn,    // pedestrian button
    output logic [2:0] ns_light,
    output logic [2:0] ew_light,
    output logic       walk_sign,  // walk indicator
    output logic       flash_sign  // flashing warning
);

    // YOUR CODE HERE
    // Key challenges:
    // 1. Latch ped_btn into a ped_pending register
    // 2. Conditional timer values based on ped_pending
    // 3. New states: WALK, FLASH
    // 4. Clear ped_pending when FLASH finishes

endmodule

💡 Hints

Latching the button: Use a separate always_ff block for ped_pending. Set on ped_btn, clear when leaving FLASH state. Timer trick: In GREEN_NS, compare timer to ped_pending ? 4'd4 : 4'd9.

버튼 래칭: ped_pending을 위한 별도의 always_ff 블록을 사용하세요. ped_btn에서 설정, FLASH 상태를 떠날 때 클리어. 타이머 트릭: GREEN_NS에서 타이머를 ped_pending ? 4'd4 : 4'd9와 비교.

module ped_traffic_light (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       ped_btn,
    output logic [2:0] ns_light,
    output logic [2:0] ew_light,
    output logic       walk_sign,
    output logic       flash_sign
);

    localparam logic [2:0] RED = 3'b100, YELLOW = 3'b010, GREEN = 3'b001;

    typedef enum logic [2:0] {
        S_GREEN_NS, S_YELLOW_NS,
        S_WALK, S_FLASH,
        S_GREEN_EW, S_YELLOW_EW
    } state_t;

    state_t state, next_state;
    logic [3:0] timer, next_timer;
    logic ped_pending, clear_ped;

    // Pedestrian latch
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            ped_pending <= 1'b0;
        else if (clear_ped)
            ped_pending <= 1'b0;
        else if (ped_btn)
            ped_pending <= 1'b1;
    end

    // State + timer register
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state <= S_GREEN_NS;
            timer <= 4'd0;
        end else begin
            state <= next_state;
            timer <= next_timer;
        end
    end

    always_comb begin
        next_state = state;
        next_timer = timer + 4'd1;
        clear_ped  = 1'b0;

        case (state)
            S_GREEN_NS: begin
                // Shorten if pedestrian waiting
                if (timer == (ped_pending ? 4'd4 : 4'd9)) begin
                    next_state = S_YELLOW_NS;
                    next_timer = 4'd0;
                end
            end
            S_YELLOW_NS: if (timer == 4'd2) begin
                next_state = ped_pending ? S_WALK : S_GREEN_EW;
                next_timer = 4'd0;
            end
            S_WALK: if (timer == 4'd5) begin
                next_state = S_FLASH;
                next_timer = 4'd0;
            end
            S_FLASH: if (timer == 4'd3) begin
                next_state = S_GREEN_EW;
                next_timer = 4'd0;
                clear_ped  = 1'b1;
            end
            S_GREEN_EW: if (timer == 4'd9) begin
                next_state = S_YELLOW_EW;
                next_timer = 4'd0;
            end
            S_YELLOW_EW: if (timer == 4'd2) begin
                next_state = S_GREEN_NS;
                next_timer = 4'd0;
            end
            default: begin
                next_state = S_GREEN_NS;
                next_timer = 4'd0;
            end
        endcase
    end

    // Moore outputs
    always_comb begin
        walk_sign  = 1'b0;
        flash_sign = 1'b0;
        case (state)
            S_GREEN_NS:  begin ns_light=GREEN;  ew_light=RED;    end
            S_YELLOW_NS: begin ns_light=YELLOW; ew_light=RED;    end
            S_WALK:      begin ns_light=RED;    ew_light=RED; walk_sign=1'b1;  end
            S_FLASH:     begin ns_light=RED;    ew_light=RED; flash_sign=1'b1; end
            S_GREEN_EW:  begin ns_light=RED;    ew_light=GREEN;  end
            S_YELLOW_EW: begin ns_light=RED;    ew_light=YELLOW; end
            default:     begin ns_light=RED;    ew_light=RED;    end
        endcase
    end

endmodule
