Exercise 1: Turnstile FSM 🚪

Design a turnstile controller with two states: LOCKED and UNLOCKED.

두 개의 상태를 가진 회전문 컨트롤러를 설계하세요: LOCKED와 UNLOCKED.

📋 Requirements

📋 요구사항

  • Inputs: clk, rst_n, coin, push
  • Output: unlocked (1 when gate is open)
  • LOCKED state: Inserting a coin → transitions to UNLOCKED. Pushing has no effect.
  • UNLOCKED state: A push → transitions back to LOCKED. Inserting another coin has no effect.
  • Reset: Goes to LOCKED
  • 입력: clk, rst_n, coin, push
  • 출력: unlocked (게이트 열려있을 때 1)
  • LOCKED 상태: coin 투입 → UNLOCKED로 전이. push는 효과 없음.
  • UNLOCKED 상태: push → LOCKED로 전이. 추가 coin은 효과 없음.
  • 리셋: LOCKED로 이동
┌────────┐ ┌──────────┐ ──► │ LOCKED │ ──coin──► │ UNLOCKED │ │ │ ◄──push── │ │ └────────┘ └──────────┘

💡 Hint: Use the 3-block pattern from the lesson. Don't forget next_state = state; as default and a default case!

💡 힌트: 레슨의 3블록 패턴을 사용하세요. next_state = state; 기본값과 default 케이스를 잊지 마세요!

typedef enum logic {
    LOCKED   = 1'b0,
    UNLOCKED = 1'b1
} turnstile_state_t;

module turnstile (
    input  logic clk,
    input  logic rst_n,
    input  logic coin,
    input  logic push,
    output logic unlocked
);

    turnstile_state_t state, next_state;

    // Block 1: State Register
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= LOCKED;
        else
            state <= next_state;
    end

    // Block 2: Next-State Logic
    always_comb begin
        next_state = state;  // Default: stay
        case (state)
            LOCKED:   if (coin) next_state = UNLOCKED;
            UNLOCKED: if (push) next_state = LOCKED;
            default:  next_state = LOCKED;
        endcase
    end

    // Block 3: Output Logic
    always_comb begin
        unlocked = (state == UNLOCKED);
    end

endmodule

Exercise 2: LED Blink Pattern FSM 💡

Design an FSM that produces a blinking pattern: ON for 2 cycles, OFF for 1 cycle, repeat.

깜박임 패턴을 생성하는 FSM을 설계하세요: 2 사이클 ON, 1 사이클 OFF, 반복.

📋 Requirements

📋 요구사항

  • Inputs: clk, rst_n, enable
  • Output: led
  • States: ON1, ON2, OFF1
  • When enable is 0, stay in current state (pause)
  • Pattern when enabled: ON1 → ON2 → OFF1 → ON1 → ...
  • LED is on during ON1 and ON2, off during OFF1
  • 입력: clk, rst_n, enable
  • 출력: led
  • 상태: ON1, ON2, OFF1
  • enable이 0이면 현재 상태 유지 (일시정지)
  • 활성화 시 패턴: ON1 → ON2 → OFF1 → ON1 → ...
  • ON1, ON2에서 LED 켜짐, OFF1에서 꺼짐

💡 Hint: The enable check goes in the next-state logic. If !enable, the default next_state = state keeps you in place.

💡 힌트: enable 검사는 다음 상태 로직에 들어갑니다. !enable이면 기본값 next_state = state가 현재 위치를 유지합니다.

typedef enum logic [1:0] {
    ON1  = 2'b00,
    ON2  = 2'b01,
    OFF1 = 2'b10
} blink_state_t;

module led_blinker (
    input  logic clk,
    input  logic rst_n,
    input  logic enable,
    output logic led
);

    blink_state_t state, next_state;

    // State register
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= ON1;
        else
            state <= next_state;
    end

    // Next-state logic
    always_comb begin
        next_state = state;  // Default: stay (handles !enable)
        if (enable) begin
            case (state)
                ON1:  next_state = ON2;
                ON2:  next_state = OFF1;
                OFF1: next_state = ON1;
                default: next_state = ON1;
            endcase
        end
    end

    // Output logic
    always_comb begin
        led = (state == ON1) || (state == ON2);
    end

endmodule

Exercise 3: Bug Hunt 🐛

Find and fix ALL the bugs in this FSM. There are 4 bugs.

이 FSM의 모든 버그를 찾아 수정하세요. 4개의 버그가 있습니다.

typedef enum logic [1:0] {
    IDLE = 2'b00,
    LOAD = 2'b01,
    PROC = 2'b10,
    DONE = 2'b11
} state_t;

module buggy_fsm (
    input  logic clk, rst_n, start, loaded, finished,
    output logic busy, done_out
);
    state_t state, next_state;

    // BUG 1 is here
    always_ff @(posedge clk) begin
        if (!rst_n)
            state <= IDLE;
        else
            state <= next_state;
    end

    // BUG 2 is here
    always_comb begin
        case (state)
            IDLE: if (start) next_state = LOAD;
            LOAD: if (loaded) next_state = PROC;
            PROC: if (finished) next_state = DONE;
            DONE: next_state = IDLE;
        endcase
    end

    // BUG 3 is here
    always_ff @(posedge clk) begin
        busy     = (state == LOAD) || (state == PROC);
        done_out = (state == DONE);
    end
endmodule

💡 Hints: Think about: async reset sensitivity, default assignments, missing case handling, and output block type.

💡 힌트: 비동기 리셋 감도, 기본 할당, 누락된 케이스 처리, 출력 블록 유형을 생각해보세요.

🐛 The 4 Bugs

Bug 1: Async reset missing from sensitivity list. Should be always_ff @(posedge clk or negedge rst_n)

버그 1: 감도 리스트에 비동기 리셋 누락. always_ff @(posedge clk or negedge rst_n)이어야 함

Bug 2: Missing next_state = state; default assignment at top of always_comb. Also missing default case. Both cause latches.

버그 2: always_comb 상단에 next_state = state; 기본 할당 누락. default 케이스도 누락. 둘 다 래치를 유발.

Bug 3: Output logic should be always_comb, not always_ff. Outputs are combinational — they depend only on current state.

버그 3: 출력 로직은 always_ff가 아닌 always_comb이어야 함. 출력은 조합 논리.

Bug 4 (within Bug 2): No default case in the case statement — illegal states trap the FSM.

버그 4 (버그 2 내): case 문에 default 케이스 없음 — 불법 상태가 FSM을 가둠.
