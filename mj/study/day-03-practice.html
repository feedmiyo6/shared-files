Exercise 1: Fix the Broken Shift Register 연습 1: 고장난 시프트 레지스터 고치기

The following shift register is broken. Fix it so data properly shifts through q1 → q2 → q3 over 3 clock cycles.

다음 시프트 레지스터가 고장났습니다. 데이터가 3 클럭 사이클에 걸쳐 q1 → q2 → q3로 제대로 이동하도록 고치세요.

// BROKEN CODE - Fix the assignment type!
module shift_register (
    input  logic clk,
    input  logic rst_n,
    input  logic d,
    output logic q1, q2, q3
);

always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        q1 = 0;  // BUG: Wrong assignment type
        q2 = 0;  // BUG
        q3 = 0;  // BUG
    end else begin
        q1 = d;   // BUG
        q2 = q1;  // BUG
        q3 = q2;  // BUG
    end
end

endmodule

💡 Hint (click to reveal)힌트 (클릭하여 보기)

Change all = to <= inside always_ff. Non-blocking ensures each flip-flop samples the OLD value of the previous stage.

always_ff 안의 모든 =를 <=로 변경하세요. Non-blocking은 각 플립플롭이 이전 단계의 이전 값을 샘플링하도록 보장합니다.

✅ Solution (click to reveal)해답 (클릭하여 보기)

module shift_register (
    input  logic clk,
    input  logic rst_n,
    input  logic d,
    output logic q1, q2, q3
);

always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        q1 <= 1'b0;
        q2 <= 1'b0;
        q3 <= 1'b0;
    end else begin
        q1 <= d;
        q2 <= q1;
        q3 <= q2;
    end
end

endmodule

Exercise 2: Swap Two Registers 연습 2: 두 레지스터 교환

Design a circuit that swaps the values of two registers on each clock edge. This is impossible with blocking but trivial with non-blocking!

각 클럭 엣지에서 두 레지스터의 값을 교환하는 회로를 설계하세요. Blocking으로는 불가능하지만 non-blocking으로는 간단합니다!

// Design a module that swaps reg_a and reg_b each cycle
// After clock: old_a → reg_b, old_b → reg_a

module swapper (
    input  logic       clk,
    input  logic       rst_n,
    input  logic [7:0] init_a,
    input  logic [7:0] init_b,
    input  logic       load,
    output logic [7:0] reg_a,
    output logic [7:0] reg_b
);

// Your code here!
// On reset: both = 0
// On load: reg_a = init_a, reg_b = init_b
// Otherwise: swap values!

endmodule

💡 Hint (click to reveal)힌트 (클릭하여 보기)

With non-blocking, both assignments evaluate their RHS before any update happens:

Non-blocking을 사용하면 두 할당 모두 업데이트가 발생하기 전에 RHS를 평가합니다:

reg_a <= reg_b;  // Reads old reg_b
reg_b <= reg_a;  // Reads old reg_a

✅ Solution (click to reveal)해답 (클릭하여 보기)

module swapper (
    input  logic       clk,
    input  logic       rst_n,
    input  logic [7:0] init_a,
    input  logic [7:0] init_b,
    input  logic       load,
    output logic [7:0] reg_a,
    output logic [7:0] reg_b
);

always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        reg_a <= 8'b0;
        reg_b <= 8'b0;
    end else if (load) begin
        reg_a <= init_a;
        reg_b <= init_b;
    end else begin
        // Magic of non-blocking: no temp needed!
        reg_a <= reg_b;
        reg_b <= reg_a;
    end
end

endmodule

Exercise 3: Mixed Combinational and Sequential 연습 3: 조합 논리와 순차 논리 혼합

Complete this counter module using BOTH blocking (for comb) and non-blocking (for seq):

조합 논리에는 blocking, 순차 논리에는 non-blocking을 사용하여 이 카운터 모듈을 완성하세요:

module smart_counter (

✅ Solution (click to reveal)해답 (클릭하여 보기)

module smart_counter (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       up_down,
    input  logic       enable,
    output logic [7:0] count,
    output logic       at_max,
    output logic       at_min
);

logic [7:0] next_count;

// Combinational: compute next value (BLOCKING)
always_comb begin
    if (up_down)
        next_count = count + 8'd1;  // =
    else
        next_count = count - 8'd1;  // =
end

// Combinational: flags (BLOCKING)
always_comb begin
    at_max = (count == 8'hFF);  // =
    at_min = (count == 8'h00);  // =
end

// Sequential: update register (NON-BLOCKING)
always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        count <= 8'b0;            // <=
    else if (enable)
        count <= next_count;      // <=
end

endmodule

🎯 Key Takeaways 🎯 핵심 요점

  • always_comb → = (blocking) for combinational logic
  • always_comb → = (blocking) 조합 논리에 사용
  • always_ff → <= (non-blocking) for sequential logic
  • always_ff → <= (non-blocking) 순차 논리에 사용
  • Non-blocking makes parallel updates easy (swap, shift)
  • Non-blocking은 병렬 업데이트를 쉽게 만듭니다 (교환, 시프트)
