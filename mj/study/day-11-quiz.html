Q1. What is setup time?

Q1. 셋업 타임이란 무엇인가요?

  • A) Time after the clock edge that data must remain stable
  • A) 클럭 에지 이후 데이터가 안정되어야 하는 시간
  • B) Minimum time data must be stable before the clock edge
  • B) 클럭 에지 전에 데이터가 안정되어야 하는 최소 시간
  • C) The propagation delay through combinational logic
  • C) 조합 논리를 통한 전파 지연
  • D) The delay from clock input to Q output
  • D) 클럭 입력에서 Q 출력까지의 지연

✅ B — Setup time is the minimum time data must be stable before the active clock edge. Option A describes hold time, C describes combinational delay, and D describes clock-to-Q delay.

✅ B — 셋업 타임은 유효 클럭 에지 전에 데이터가 안정되어야 하는 최소 시간입니다. A는 홀드 타임, C는 조합 지연, D는 클럭-투-Q 지연입니다.

  • A) 1.00 GHz
  • A) 1.00 GHz

  • C) 1.43 GHz
  • D) 2.00 GHz
  • D) 2.00 GHz

✅ C — F_max = 1 / (120 + 500 + 80)ps = 1/700ps = 1.43 GHz.

Q3. What does "negative slack" in a timing report indicate?

Q3. 타이밍 리포트에서 "음의 슬랙(negative slack)"은 무엇을 나타내나요?

  • A) A setup time violation — data arrives too late
  • A) 셋업 타임 위반 — 데이터가 너무 늦게 도착
  • B) The design has extra timing margin
  • B) 설계에 여유 타이밍 마진이 있음
  • C) A hold time violation
  • C) 홀드 타임 위반
  • D) The clock is running too slowly
  • D) 클럭이 너무 느리게 동작

✅ A — Negative slack means data required time minus data arrival time is negative, meaning data arrives after the deadline. This is a setup violation.

✅ A — 음의 슬랙은 데이터 요구 시간에서 데이터 도착 시간을 뺀 값이 음수임을 의미하며, 데이터가 기한 후에 도착함을 뜻합니다. 이것은 셋업 위반입니다.

Q4. Which fix for a setup violation adds latency but enables higher frequency?

Q4. 셋업 위반을 수정하는 방법 중 지연을 추가하지만 더 높은 주파수를 가능하게 하는 것은?

  • A) Reducing clock frequency
  • A) 클럭 주파수 감소
  • B) Pipelining (inserting registers)
  • B) 파이프라이닝 (레지스터 삽입)
  • C) Using faster library cells
  • C) 더 빠른 라이브러리 셀 사용
  • D) Removing flip-flops
  • D) 플립플롭 제거

✅ B — Pipelining breaks a long combinational path into shorter stages. Each stage is faster (higher frequency), but the total result takes more clock cycles (added latency).

✅ B — 파이프라이닝은 긴 조합 경로를 더 짧은 단계로 분할합니다. 각 단계가 더 빠르지만(높은 주파수), 전체 결과는 더 많은 클럭 사이클이 필요합니다(지연 추가).

Q5. Setup time is a property of:

Q5. 셋업 타임은 다음의 속성입니다:

  • A) The combinational logic between flip-flops
  • A) 플립플롭 사이의 조합 논리
  • B) The clock network
  • B) 클럭 네트워크
  • C) The destination flip-flop (silicon technology)
  • C) 대상 플립플롭 (실리콘 기술)
  • D) The source flip-flop
  • D) 소스 플립플롭

✅ C — Setup time is an intrinsic property of the destination flip-flop, determined by the silicon technology and cell library. It cannot be changed by the designer.

✅ C — 셋업 타임은 실리콘 기술과 셀 라이브러리에 의해 결정되는 대상 플립플롭의 고유 속성입니다. 설계자가 변경할 수 없습니다.

Q6. 설계가 1 GHz로 동작하고 T_cq = 100ps, T_su = 50ps일 때, 허용되는 최대 T_comb는?

  • A) 1000ps

  • D) 850ps

✅ D — T_clk = 1/1GHz = 1000ps. T_comb ≤ T_clk - T_cq - T_su = 1000 - 100 - 50 = 850ps.

Q7. What happens when a setup time violation occurs?

Q7. 셋업 타임 위반이 발생하면 어떻게 되나요?

  • A) The flip-flop always outputs 0
  • A) 플립플롭이 항상 0을 출력
  • B) The flip-flop may capture wrong data or become metastable
  • B) 플립플롭이 잘못된 데이터를 잡거나 메타스테이블 상태가 될 수 있음
  • C) The clock stops working
  • C) 클럭이 작동을 멈춤
  • D) The flip-flop holds its previous value
  • D) 플립플롭이 이전 값을 유지

✅ B — A setup violation means data wasn't stable long enough. The flip-flop might capture the old value, the new value, or enter metastability where the output oscillates unpredictably.

✅ B — 셋업 위반은 데이터가 충분히 오래 안정되지 않았음을 의미합니다. 플립플롭은 이전 값, 새 값을 잡거나, 출력이 예측 불가능하게 진동하는 메타스테이빌리티에 빠질 수 있습니다.

Q8. Which tool performs setup time analysis in industry?

Q8. 산업에서 셋업 타임 분석을 수행하는 도구는?

  • A) Static Timing Analysis (STA) tools
  • A) 정적 타이밍 분석(STA) 도구
  • B) Logic simulators only
  • B) 로직 시뮬레이터만
  • C) Waveform viewers
  • C) 파형 뷰어
  • D) Text editors
  • D) 텍스트 에디터

✅ A — STA tools like Synopsys PrimeTime and Cadence Tempus analyze every timing path without simulation. They're the primary method for verifying setup (and hold) time constraints.

✅ A — Synopsys PrimeTime과 Cadence Tempus 같은 STA 도구는 시뮬레이션 없이 모든 타이밍 경로를 분석합니다. 셋업(및 홀드) 타임 제약을 검증하는 주요 방법입니다.

Q9. In the equation T_clk ≥ T_cq + T_comb + T_su, what does T_cq represent?

Q9. T_clk ≥ T_cq + T_comb + T_su 방정식에서 T_cq는 무엇을 나타내나요?

  • A) Clock period
  • A) 클럭 주기
  • B) Setup time of the destination flip-flop
  • B) 대상 플립플롭의 셋업 타임
  • C) Clock-to-Q delay of the source flip-flop
  • C) 소스 플립플롭의 클럭-투-Q 지연
  • D) Combinational logic delay
  • D) 조합 논리 지연

✅ C — T_cq (clock-to-Q) is the delay from the clock edge to the output of the source flip-flop becoming valid. It's how long the source FF takes to produce its output after being clocked.

✅ C — T_cq(클럭-투-Q)는 클럭 에지에서 소스 플립플롭의 출력이 유효해지기까지의 지연입니다. 소스 FF가 클럭된 후 출력을 생성하는 데 걸리는 시간입니다.

Q10. Using faster library cells to fix setup violations has which trade-off?

Q10. 셋업 위반을 수정하기 위해 더 빠른 라이브러리 셀을 사용하면 어떤 트레이드오프가 있나요?

  • A) Increased latency
  • A) 지연 시간 증가
  • B) Higher power consumption
  • B) 전력 소비 증가
  • C) Lower frequency
  • C) 주파수 감소
  • D) No trade-off
  • D) 트레이드오프 없음

✅ B — Faster cells use more current to switch quickly, which increases power consumption. This is one of the fundamental area/power/performance trade-offs in chip design.

✅ B — 더 빠른 셀은 빠르게 스위칭하기 위해 더 많은 전류를 사용하여 전력 소비가 증가합니다. 이것은 칩 설계에서 면적/전력/성능의 기본적인 트레이드오프 중 하나입니다.
