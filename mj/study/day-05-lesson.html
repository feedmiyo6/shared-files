Today we learn how to verify our designs actually work. Writing RTL code is only half the job — simulation and testbenches are how you prove correctness before anything touches silicon.

오늘은 설계가 실제로 동작하는지 검증하는 방법을 배웁니다. RTL 코드를 작성하는 것은 절반일 뿐 — 시뮬레이션과 테스트벤치가 실리콘에 들어가기 전에 정확성을 증명하는 방법입니다.

1. What Is Simulation? 1. 시뮬레이션이란?

Simulation runs your SystemVerilog code on a computer, modeling how the hardware would behave cycle-by-cycle. The simulator evaluates all signal changes, propagates values, and lets you observe outputs over time.

시뮬레이션은 SystemVerilog 코드를 컴퓨터에서 실행하여 하드웨어가 사이클별로 어떻게 동작할지 모델링합니다. 시뮬레이터는 모든 신호 변화를 평가하고 값을 전파하며, 시간에 따른 출력을 관찰할 수 있게 합니다.

🔑 Key Simulation Concepts 🔑 핵심 시뮬레이션 개념

  • DUT (Design Under Test) — the module you're verifying
  • DUT (Design Under Test) — 검증 대상 모듈
  • Testbench — a wrapper that drives inputs and checks outputs
  • 테스트벤치 — 입력을 구동하고 출력을 확인하는 래퍼
  • Stimulus — the input patterns you apply
  • 스티뮬러스 — 적용하는 입력 패턴
  • Waveform — visual timeline of signal values
  • 파형 — 신호 값의 시각적 타임라인

2. Testbench Structure 2. 테스트벤치 구조

A testbench is a special module with no ports. It instantiates the DUT, generates a clock, drives inputs, and monitors outputs. Here's the basic skeleton:

테스트벤치는 포트가 없는 특수 모듈입니다. DUT를 인스턴스화하고, 클록을 생성하고, 입력을 구동하고, 출력을 모니터링합니다. 기본 구조는 다음과 같습니다:

module tb_counter;

    // 1. Declare testbench signals
    logic       clk;
    logic       rst_n;
    logic       enable;
    logic [3:0] count;

    // 2. Instantiate the DUT
    counter dut (
        .clk    (clk),
        .rst_n  (rst_n),
        .enable (enable),
        .count  (count)
    );

    // 3. Generate clock — 10ns period
    initial clk = 0;
    always #5 clk = ~clk;

    // 4. Stimulus
    initial begin
        rst_n  = 0;
        enable = 0;
        #20;              // Hold reset for 20ns
        rst_n  = 1;
        #10;
        enable = 1;
        #100;             // Let it count for a while
        enable = 0;
        #30;
        $finish;
    end

endmodule

💡 Tip: The testbench module has no port list — it's the "top" of simulation. Everything connects internally.

💡 팁: 테스트벤치 모듈에는 포트 리스트가 없습니다 — 시뮬레이션의 "최상위"입니다. 모든 것이 내부적으로 연결됩니다.

3. Clock Generation 3. 클록 생성

Every synchronous design needs a clock. There are two common patterns:

모든 동기 설계에는 클록이 필요합니다. 두 가지 일반적인 패턴이 있습니다:

// Pattern 1: initial + always (most common)
initial clk = 0;
always #5 clk = ~clk;  // 10ns period → 100MHz

// Pattern 2: forever inside initial
initial begin
    clk = 0;
    forever #5 clk = ~clk;
end

⏱️ Time Units ⏱️ 시간 단위

The # symbol is a time delay. The actual time depends on the `timescale directive:

# 기호는 시간 지연입니다. 실제 시간은 `timescale 지시자에 따라 달라집니다:

`timescale 1ns / 1ps   // time_unit / time_precision
// #5 means 5ns, precision down to 1ps

4. System Tasks: $display, $monitor, $finish 4. 시스템 태스크: $display, $monitor, $finish

SystemVerilog provides built-in system tasks (prefixed with $) for simulation control and output:

SystemVerilog는 시뮬레이션 제어와 출력을 위한 내장 시스템 태스크($ 접두사)를 제공합니다:

System TaskPurposeWhen It Runs
$display Print once (like printf) 한 번 출력 (printf처럼) When the statement is reached 해당 문장에 도달했을 때
$monitor Print whenever any argument changes 인수가 변경될 때마다 출력 Continuously (automatic) 계속 (자동)
$write Print without newline 줄바꿈 없이 출력 When the statement is reached 해당 문장에 도달했을 때
$finish End the simulation 시뮬레이션 종료 When the statement is reached 해당 문장에 도달했을 때
$time Returns current simulation time 현재 시뮬레이션 시간 반환 Evaluated inline 인라인 평가 
// $display — print once with format string
$display("Time=%0t rst=%b enable=%b count=%d",
         $time, rst_n, enable, count);

// $monitor — auto-prints when any signal changes
$monitor("[%0t] count=%d enable=%b",
         $time, count, enable);

// Format specifiers
// %b = binary, %d = decimal, %h = hex, %0t = time
// %s = string, %0d = decimal (no padding)

⚠️ Common Mistake: $monitor Overuse ⚠️ 흔한 실수: $monitor 남용

Only one $monitor can be active at a time! Calling it again replaces the previous one. For multiple signal watches, include them all in one $monitor call, or use $display at specific points.

한 번에 하나의 $monitor만 활성화될 수 있습니다! 다시 호출하면 이전 것을 대체합니다. 여러 신호를 감시하려면 하나의 $monitor 호출에 모두 포함하거나, 특정 시점에서 $display를 사용하세요.

5. Complete Testbench Example 5. 완전한 테스트벤치 예제

Let's write a full testbench for a 4-bit counter with enable and reset:

enable과 reset이 있는 4비트 카운터의 전체 테스트벤치를 작성해 봅시다:

`timescale 1ns / 1ps

module tb_counter;

    // Signals
    logic       clk, rst_n, enable;
    logic [3:0] count;

    // DUT instantiation
    counter #(.WIDTH(4)) dut (.*);  // .* auto-connects matching names

    // Clock: 100MHz (10ns period)
    initial clk = 0;
    always #5 clk = ~clk;

    // Monitor output continuously
    initial
        $monitor("[%0t] rst_n=%b en=%b count=%4b (%0d)",
                 $time, rst_n, enable, count, count);

    // Stimulus
    initial begin
        // Phase 1: Reset
        rst_n  = 0;
        enable = 0;
        #25;  // Hold reset for 2.5 clock cycles

        // Phase 2: Release reset, start counting
        rst_n = 1;
        #10;
        enable = 1;
        $display("--- Counting started ---");
        #100;  // Count for 10 clocks

        // Phase 3: Pause counting
        enable = 0;
        $display("--- Counting paused ---");
        #30;

        // Phase 4: Resume
        enable = 1;
        #50;

        // Phase 5: Test reset during count
        rst_n = 0;
        #20;
        rst_n = 1;
        #40;

        $display("--- Simulation complete ---");
        $finish;
    end

    // Optional: dump waveforms for viewer
    initial begin
        $dumpfile("counter.vcd");
        $dumpvars(0, tb_counter);
    end

endmodule

6. Waveform Viewing 6. 파형 보기

Waveforms show signal values over time. They are the most powerful debugging tool in digital design.

파형은 시간에 따른 신호 값을 보여줍니다. 디지털 설계에서 가장 강력한 디버깅 도구입니다.

📊 How to Generate Waveforms 📊 파형 생성 방법 

// Add these lines to your testbench:
initial begin
    $dumpfile("output.vcd");    // VCD = Value Change Dump
    $dumpvars(0, tb_name);    // 0 = dump ALL signals in hierarchy
end
  • $dumpfile — sets the output filename (.vcd format)
  • $dumpfile — 출력 파일명 설정 (.vcd 형식)
  • $dumpvars(0, module) — level 0 means dump everything below that module
  • $dumpvars(0, module) — 레벨 0은 해당 모듈 아래 모든 것을 덤프
  • View with: GTKWave (free), Surfer, or EDA Playground's built-in viewer
  • 뷰어: GTKWave (무료), Surfer, 또는 EDA Playground 내장 뷰어

7. Simulation Flow 7. 시뮬레이션 흐름

🔄 Typical Simulation Workflow 🔄 일반적인 시뮬레이션 워크플로우

  1. Write RTL — your design module(s)
  2. RTL 작성 — 설계 모듈
  3. Write testbench — instantiate DUT, generate clock, create stimulus
  4. 테스트벤치 작성 — DUT 인스턴스화, 클록 생성, 스티뮬러스 작성
  5. Compile — vlog *.sv (ModelSim) or just click Run (EDA Playground)
  6. 컴파일 — vlog *.sv (ModelSim) 또는 Run 클릭 (EDA Playground)
  7. Simulate — vsim tb_name then run -all
  8. 시뮬레이션 — vsim tb_name 후 run -all
  9. Analyze — check console output + waveforms
  10. 분석 — 콘솔 출력 + 파형 확인
  11. Debug & iterate — fix issues, re-run
  12. 디버그 & 반복 — 문제 수정, 재실행

8. Self-Checking Testbenches 8. 자체 검증 테스트벤치

Professional testbenches don't rely on eyeballing waveforms — they automatically check expected values:

전문적인 테스트벤치는 파형을 눈으로 확인하는 것에 의존하지 않고 — 기대값을 자동으로 확인합니다:

initial begin
    // After reset, count should be 0
    rst_n = 0; #20;
    rst_n = 1; #5;

    assert (count == 4'b0000)
        $display("PASS: Reset works");
    else
        $error("FAIL: count=%b after reset", count);

    // Enable counting, check after 3 clocks
    enable = 1;
    repeat(3) @(posedge clk);
    #1;  // Small delay to let output settle

    assert (count == 4'd3)
        $display("PASS: Count reached 3");
    else
        $error("FAIL: expected 3, got %0d", count);
end

💡 assert is SystemVerilog's built-in check. $error prints but doesn't stop — use $fatal if you want to halt on failure.

💡 assert는 SystemVerilog의 내장 검사입니다. $error는 출력만 하고 멈추지 않습니다 — 실패 시 중단하려면 $fatal을 사용하세요.

9. Timing in Testbenches 9. 테스트벤치에서의 타이밍

ConstructMeaningExample
#N Wait N time units N 시간 단위 대기 #10;
@(posedge clk) Wait for rising clock edge 클록 상승 에지 대기 @(posedge clk);
@(negedge clk) Wait for falling clock edge 클록 하강 에지 대기 @(negedge clk);
repeat(N) Do N times N번 반복 repeat(5) @(posedge clk);
wait(expr) Wait until expression is true 표현식이 참이 될 때까지 대기 wait(count == 4'hF);

⚠️ Don't Forget $finish! ⚠️ $finish을 잊지 마세요!

Without $finish, your simulation runs forever (the clock never stops). Always end your stimulus block with $finish;

$finish 없이는 시뮬레이션이 영원히 실행됩니다 (클록이 멈추지 않음). 항상 스티뮬러스 블록을 $finish;로 끝내세요.
