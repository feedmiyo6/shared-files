FIFO Design Part 2: Full & Empty Flags FIFO 설계 파트 2: Full & Empty 플래그

Yesterday we built the pointer logic for a FIFO. Today we'll tackle the most critical part: accurately detecting full and empty conditions — the heart of FIFO correctness.

어제 우리는 FIFO의 포인터 로직을 구축했습니다. 오늘은 가장 중요한 부분인 정확한 full 및 empty 상태 감지를 다룰 것입니다 — 이는 FIFO 정확성의 핵심입니다.

The Challenge: Full vs Empty Detection 도전: Full vs Empty 감지

Here's the problem: when write_ptr == read_ptr, is the FIFO full or empty?

문제는 다음과 같습니다: write_ptr == read_ptr일 때, FIFO는 full인가요 아니면 empty인가요?

The Pointer Collision Problem 포인터 충돌 문제

  • Empty: write_ptr catches up to read_ptr (both point to same location, nothing written)
  • Empty: write_ptr이 read_ptr을 따라잡음 (둘 다 같은 위치를 가리킴, 아무것도 쓰여지지 않음)
  • Full: write_ptr wraps around and catches up to read_ptr (all locations written)
  • Full: write_ptr이 wrap around되어 read_ptr을 따라잡음 (모든 위치에 쓰여짐)

Solution: Add an extra bit to each pointer! This "MSB trick" distinguishes full from empty.

해결책: 각 포인터에 추가 비트를 더하세요! 이 "MSB 트릭"이 full과 empty를 구분합니다.

The MSB Trick Explained MSB 트릭 설명

For a FIFO with DEPTH = 8 (needs 3 address bits), we use 4-bit pointers:

DEPTH = 8(3개의 주소 비트 필요)인 FIFO의 경우, 4비트 포인터를 사용합니다: 

// 4-bit pointers for 8-entry FIFO
// Bits [3] = MSB (wrap flag), Bits [2:0] = actual address

// Empty condition: all bits match (including MSB)
assign empty = (write_ptr == read_ptr);

// Full condition: addresses match, but MSBs differ (wrapped)
assign full = (write_ptr[2:0] == read_ptr[2:0]) && 
              (write_ptr[3] != read_ptr[3]);

Why This Works 왜 이것이 작동하는가

The MSB acts as a "generation counter." Every time a pointer wraps around, its MSB toggles. Full means write has wrapped one more time than read — the addresses align but the "generations" differ.

MSB는 "세대 카운터" 역할을 합니다. 포인터가 wrap around할 때마다 MSB가 토글됩니다. Full은 write가 read보다 한 번 더 wrap around했음을 의미합니다 — 주소는 일치하지만 "세대"는 다릅니다.

Complete FIFO with Full/Empty Logic Full/Empty 로직이 포함된 완전한 FIFO 

module fifo #(
    parameter DATA_WIDTH = 32,
    parameter DEPTH = 8,
    parameter ADDR_WIDTH = $clog2(DEPTH)  // 3 for DEPTH=8
)(
    input  logic clk,
    input  logic rst_n,
    
    // Write interface
    input  logic wr_en,
    input  logic [DATA_WIDTH-1:0] wr_data,
    output logic full,
    
    // Read interface
    input  logic rd_en,
    output logic [DATA_WIDTH-1:0] rd_data,
    output logic empty
);

    // Memory array
    logic [DATA_WIDTH-1:0] mem [DEPTH];
    
    // Pointers with extra bit for full/empty detection
    logic [ADDR_WIDTH:0] wr_ptr, rd_ptr;  // ADDR_WIDTH+1 bits!
    
    // Status flags
    assign empty = (wr_ptr == rd_ptr);
    assign full  = (wr_ptr[ADDR_WIDTH-1:0] == rd_ptr[ADDR_WIDTH-1:0]) && 
                   (wr_ptr[ADDR_WIDTH] != rd_ptr[ADDR_WIDTH]);
    
    // Write logic
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            wr_ptr <= 0;
        end else if (wr_en && !full) begin
            mem[wr_ptr[ADDR_WIDTH-1:0]] <= wr_data;
            wr_ptr <= wr_ptr + 1;
        end
    end
    
    // Read logic
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            rd_ptr <= 0;
        end else if (rd_en && !empty) begin
            rd_ptr <= rd_ptr + 1;
        end
    end
    
    // Output data (registered read)
    assign rd_data = mem[rd_ptr[ADDR_WIDTH-1:0]];

endmodule

Common Mistake: Using Address Bits Only 흔한 실수: 주소 비트만 사용하기 

// WRONG: Can't distinguish full from empty!
assign full = (wr_ptr[2:0] == rd_ptr[2:0]);  // Same as empty!

Without the MSB comparison, full and empty have identical conditions. The extra bit is essential!

MSB 비교 없이는 full과 empty가 동일한 조건을 가집니다. 추가 비트가 필수적입니다!

Almost-Full & Almost-Empty (Optional) Almost-Full & Almost-Empty (선택사항)

Many designs need "almost" flags for flow control — to prevent overflow/underflow when crossing clock domains or managing backpressure.

많은 설계에서 flow control을 위해 "almost" 플래그가 필요합니다 — clock domain crossing 시 오버플로우/언더플로우를 방지하거나 backpressure를 관리하기 위해 사용됩니다. 

// Almost flags with programmable threshold
parameter ALMOST_FULL_THRESH = DEPTH - 2;
parameter ALMOST_EMPTY_THRESH = 2;

logic [ADDR_WIDTH:0] fifo_count;

// Calculate occupancy (tricky with wraparound!)
always_comb begin
    if (wr_ptr[ADDR_WIDTH] == rd_ptr[ADDR_WIDTH])
        fifo_count = wr_ptr - rd_ptr;
    else
        fifo_count = (2**ADDR_WIDTH + wr_ptr) - rd_ptr;
end

assign almost_full  = (fifo_count >= ALMOST_FULL_THRESH);
assign almost_empty = (fifo_count <= ALMOST_EMPTY_THRESH);

Key Takeaways 핵심 요약

  • MSB Trick: Use N+1 bits for pointers in an N-bit address FIFO to distinguish full from empty
  • MSB 트릭: N비트 주소 FIFO에서 full과 empty를 구분하기 위해 N+1비트 포인터 사용
  • Empty: All pointer bits match (including MSB)
  • Empty: 모든 포인터 비트가 일치 (MSB 포함)
  • Full: Lower bits match, but MSBs differ (wrapped around)
  • Full: 하위 비트는 일치하지만 MSB는 다름 (wrap around됨)
  • Guard writes: Only write when !full
  • 쓰기 보호: !full일 때만 쓰기
  • Guard reads: Only read when !empty
  • 읽기 보호: !empty일 때만 읽기
