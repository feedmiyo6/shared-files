Q1. In a Moore machine, the output depends on:Moore 머신에서 출력은 무엇에 의존합니까?

  • A) Current input only현재 입력만
  • B) Current state only현재 상태만
  • C) Current state and current input현재 상태와 현재 입력
  • D) Previous state and current input이전 상태와 현재 입력

✅ B) Moore machines output depends ONLY on the current state. This is the defining characteristic.

✅ B) Moore 머신의 출력은 현재 상태에만 의존합니다. 이것이 정의적 특성입니다.

Q2. Which machine type typically requires fewer states?어떤 머신 유형이 일반적으로 더 적은 상태를 필요로 합니까?

  • A) MooreMoore
  • B) MealyMealy
  • C) They always have the same number항상 같은 수
  • D) It depends on the clock frequency클럭 주파수에 따라 다름

✅ B) Mealy machines can combine state + input for outputs, so they often don't need separate states to represent different outputs.

✅ B) Mealy 머신은 상태 + 입력을 결합하여 출력할 수 있으므로, 다른 출력을 나타내기 위한 별도의 상태가 필요 없는 경우가 많습니다.

Q3. A Mealy output can change:Mealy 출력은 언제 변할 수 있습니까?

  • A) Only on clock edges클럭 에지에서만
  • B) Only on reset리셋 시에만
  • C) Within a clock cycle when inputs change입력이 변할 때 클럭 사이클 내에서
  • D) Only after two clock cycles두 클럭 사이클 후에만

✅ C) Since Mealy outputs depend on inputs combinationally, they can change mid-cycle whenever the input changes. This is both a feature (faster) and a risk (glitches).

✅ C) Mealy 출력은 입력에 조합적으로 의존하므로, 입력이 변할 때마다 사이클 중간에 변할 수 있습니다.

Q4. What is the main risk of unregistered Mealy outputs?등록되지 않은 Mealy 출력의 주요 위험은 무엇입니까?

  • A) Output glitches출력 글리치
  • B) Too many states너무 많은 상태
  • C) High power consumption높은 전력 소비
  • D) Cannot be synthesized합성할 수 없음

✅ A) Since Mealy outputs are combinational, input changes can cause transient glitches that may be captured incorrectly by downstream registers.

✅ A) Mealy 출력은 조합적이므로, 입력 변화가 일시적 글리치를 일으켜 하류 레지스터에 잘못 캡처될 수 있습니다.

Q5. Look at this output assignment:
assign out = (state == S2);
Is this Moore or Mealy?이 출력 할당을 보세요:
assign out = (state == S2);
이것은 Moore입니까, Mealy입니까?

  • A) Moore — depends on state onlyMoore — 상태에만 의존
  • B) Mealy — uses combinational logicMealy — 조합 로직 사용
  • C) Neither — it's invalid둘 다 아님 — 유효하지 않음
  • D) Cannot determine without seeing the testbench테스트벤치를 보지 않으면 판단 불가

✅ A) The output depends only on state — no input signals involved. That's the definition of Moore.

✅ A) 출력은 state에만 의존합니다 — 입력 신호가 포함되지 않았습니다. 이것이 Moore의 정의입니다.

Q6. Look at this output assignment:
assign out = (state == S1) && din;
Is this Moore or Mealy?이 출력 할당을 보세요:
assign out = (state == S1) && din;
이것은 Moore입니까, Mealy입니까?

  • A) Moore — state drives the outputMoore — 상태가 출력을 구동
  • B) Mealy — output depends on state AND inputMealy — 출력이 상태와 입력에 의존
  • C) Registered Mealy레지스터드 Mealy
  • D) Invalid — can't AND state with input유효하지 않음 — 상태와 입력을 AND할 수 없음

✅ B) The output depends on both state and din (an input). That makes it Mealy.

✅ B) 출력이 state와 din(입력) 모두에 의존합니다. 이것이 Mealy입니다.

Q7. What is a "registered Mealy" machine?"레지스터드 Mealy" 머신이란 무엇입니까?

  • A) A Mealy machine with more registers in the state상태에 더 많은 레지스터가 있는 Mealy 머신
  • B) A Moore machine with input-dependent transitions입력 의존 전이가 있는 Moore 머신
  • C) A Mealy machine whose output is captured by a flip-flop출력이 플립플롭에 캡처되는 Mealy 머신
  • D) A Mealy machine that uses gray encoding그레이 인코딩을 사용하는 Mealy 머신

✅ C) Registered Mealy adds a flip-flop on the output, giving you Mealy's fewer states with Moore's glitch-free output quality.

✅ C) 레지스터드 Mealy는 출력에 플립플롭을 추가하여, Mealy의 적은 상태 수와 Moore의 글리치 없는 출력 품질을 모두 얻습니다.

Q8. If a Moore machine has N states for a given task, how many states would the equivalent Mealy machine likely have?Moore 머신이 주어진 작업에 N개 상태가 있다면, 동등한 Mealy 머신은 몇 개의 상태를 가질까요?

  • A) Exactly N정확히 N
  • B) ≤ N (same or fewer)≤ N (같거나 적음)
  • C) ≥ N (same or more)≥ N (같거나 많음)
  • D) Always N/2항상 N/2

✅ B) Mealy can often merge states that differ only in output, so it uses the same or fewer states.

✅ B) Mealy는 출력만 다른 상태를 병합할 수 있으므로, 같거나 더 적은 상태를 사용합니다.

Q9. Why are Moore outputs considered "safer" for control signals?Moore 출력이 제어 신호에 "더 안전"하다고 여겨지는 이유는?

  • A) They use less power전력을 덜 사용
  • B) They are always high항상 높음
  • C) They can't be wrong틀릴 수 없음
  • D) They are synchronized to the clock and glitch-free클럭에 동기화되어 글리치가 없음

✅ D) Moore outputs change only when state changes (on clock edges), so they're inherently synchronized and don't have combinational glitches.

✅ D) Moore 출력은 상태가 변할 때(클럭 에지에서)만 변하므로, 본질적으로 동기화되어 조합 글리치가 없습니다.

✅ A) Mealy 출력이 (state == SAW_0) && din이므로, SAW_0 상태에서 din이 1이 되는 순간 출력이 올라갑니다 — 같은 사이클, 대기 없음.

  • B) Mealy — need the fastest possible responseMealy — 가능한 가장 빠른 응답 필요

✅ A) When driving cross-domain signals, a glitch could be captured as a false write. Moore's registered output prevents this.

✅ A) 크로스 도메인 신호를 구동할 때, 글리치가 잘못된 쓰기로 캡처될 수 있습니다. Moore의 레지스터된 출력이 이를 방지합니다.
