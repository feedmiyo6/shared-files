Q1. What is the primary purpose of an arbiter?

Select the best answer:

가장 적절한 답을 선택하세요:

  • A) To increase clock frequency
  • B) To decide which master gets access to a shared resource
  • C) To synchronize clock domains
  • D) To reset the system after a fault

B is correct. An arbiter's job is to accept requests from multiple masters and grant access to exactly one at a time, preventing bus contention.

B가 정답입니다. 아비터의 역할은 여러 마스터의 요청을 받아 한 번에 정확히 하나에게만 접근 권한을 부여하여 버스 충돌을 방지하는 것입니다.

Q2. In a 4-bit fixed-priority arbiter (bit 0 = highest), what is the grant for req = 4'b1010?

  • A) 4'b1000
  • B) 4'b0010
  • C) 4'b1010
  • D) 4'b0001

B is correct. req = 4'b1010 means Masters 1 and 3 are requesting. Bit 1 has higher priority than bit 3, so grant = 4'b0010.

B가 정답입니다. req = 4'b1010은 마스터 1과 3이 요청 중임을 의미합니다. 비트 1이 비트 3보다 높은 우선순위이므로 grant = 4'b0010입니다.

Q3. What is the fundamental weakness of fixed-priority arbitration?

  • A) It requires too many flip-flops
  • B) It cannot handle more than 2 masters
  • C) Low-priority masters can starve
  • D) It is too slow for high-frequency designs

C is correct. If a higher-priority master always has a request pending, lower-priority masters will never receive a grant — this is called starvation.

C가 정답입니다. 높은 우선순위 마스터가 항상 요청을 걸고 있으면, 낮은 우선순위 마스터는 절대 승인을 받지 못합니다 — 이를 기아 상태(starvation)라고 합니다.

Q4. How does round-robin arbitration prevent starvation?

  • A) By using a higher clock frequency
  • B) By rotating priority so the last winner gets lowest priority next
  • C) By granting all requests simultaneously
  • D) By randomly selecting a master

B is correct. After granting, the pointer/mask advances so the winning master becomes lowest priority. This guarantees every master eventually gets served.

B가 정답입니다. 승인 후 포인터/마스크가 이동하여 승자가 최저 우선순위가 됩니다. 이렇게 하면 모든 마스터가 결국 서비스를 받게 됩니다.

Q5. The expression grant = req & (~req + 1) does what?

  • A) Sets all bits of grant
  • B) Isolates the highest set bit
  • C) Isolates the lowest set bit
  • D) Inverts the request vector

C is correct. ~req + 1 is the two's complement (negation). ANDing with the original isolates the lowest set bit. This is a fundamental bit manipulation trick used in priority encoders.

C가 정답입니다. ~req + 1은 2의 보수(부정)입니다. 원본과 AND하면 최하위 설정 비트가 분리됩니다. 이것은 우선순위 인코더에 사용되는 기본적인 비트 조작 기법입니다.

Q6. In a 4-master round-robin arbiter, what is the maximum number of cycles a master must wait before getting a grant?

  • A) 1 cycle
  • B) 3 cycles (N-1)
  • C) 4 cycles (N)
  • D) Unbounded

B is correct. In the worst case, the other N-1 masters all get served before you. With 4 masters, you wait at most 3 cycles.

B가 정답입니다. 최악의 경우, 다른 N-1개의 마스터가 모두 먼저 서비스됩니다. 4개 마스터의 경우 최대 3사이클 대기합니다.

Q7. What does the "mask" do in a mask-based round-robin arbiter?

  • A) Blocks the clock to certain masters
  • B) Suppresses requests from already-served masters in the current round
  • C) Encrypts the grant signal
  • D) Doubles the priority of the next master

B is correct. The mask clears bits for masters that have already received a grant in this round. When all bits are cleared, the mask resets and a new round begins.

B가 정답입니다. 마스크는 이번 라운드에서 이미 승인을 받은 마스터의 비트를 클리어합니다. 모든 비트가 클리어되면 마스크가 리셋되고 새 라운드가 시작됩니다.

Q8. Fixed-priority arbitration is purely combinational (no clock needed). True or False?

  • A) True
  • B) False

A (True) is correct. Fixed-priority arbitration is a simple priority encoder — pure combinational logic with no state. Round-robin, by contrast, needs a register to track the rotating priority.

A (True)가 정답입니다. 고정 우선순위 중재는 간단한 우선순위 인코더 — 상태가 없는 순수 조합 논리입니다. 반면 라운드 로빈은 회전하는 우선순위를 추적하는 레지스터가 필요합니다.

Q9. In weighted round-robin with weights [3, 1, 1, 1], what percentage of bandwidth does Master 0 get?

  • A) 25%
  • B) 33%
  • C) 50%
  • D) 75%

C is correct. Total weight = 3+1+1+1 = 6. Master 0 gets 3/6 = 50% of the bandwidth.

C가 정답입니다. 총 가중치 = 3+1+1+1 = 6. Master 0은 3/6 = 50%의 대역폭을 받습니다.

Q10. Which arbitration scheme would you use for interrupt handling where some interrupts are more critical?

  • A) Round-robin
  • B) Fixed-priority
  • C) Random
  • D) No arbitration needed

B is correct. Interrupts have inherent urgency levels (e.g., NMI > timer > keyboard). Fixed-priority ensures the most critical interrupt is always handled first.

B가 정답입니다. 인터럽트는 본질적인 긴급성 수준이 있습니다(예: NMI > 타이머 > 키보드). 고정 우선순위는 가장 중요한 인터럽트가 항상 먼저 처리되도록 보장합니다.

Q11. In the mask-based round-robin, what happens when masked_req is all zeros?

  • A) The arbiter stalls until a new request arrives
  • B) It falls back to unmasked (raw) priority encoding and resets the mask
  • C) All grants are asserted simultaneously
  • D) The system resets

B is correct. When all served masters are masked out, the arbiter falls back to raw_grant (unmasked priority encoding) and resets the mask. This starts a new round.

B가 정답입니다. 서비스된 모든 마스터가 마스크 아웃되면, 아비터는 raw_grant(마스크되지 않은 우선순위 인코딩)로 폴백하고 마스크를 리셋합니다. 새 라운드가 시작됩니다.

Q12. Where would you typically find round-robin arbitration in an SoC?

  • A) Clock generation PLL
  • B) AXI bus interconnect for shared memory access
  • C) Power-on reset circuit
  • D) Voltage regulator

B is correct. AXI interconnects use round-robin (or configurable arbitration) when multiple bus masters compete for the same slave (e.g., shared SRAM). This ensures fair bandwidth allocation.

B가 정답입니다. AXI 인터커넥트는 여러 버스 마스터가 같은 슬레이브(예: 공유 SRAM)를 두고 경쟁할 때 라운드 로빈(또는 설정 가능한 중재)을 사용합니다. 이는 공정한 대역폭 할당을 보장합니다.
