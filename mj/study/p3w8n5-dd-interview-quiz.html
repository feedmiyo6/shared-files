1 Describe the overall ASIC design flow. Name all major stages.전체 ASIC 설계 흐름을 설명하세요. 모든 주요 단계를 명명하세요.

8 stages (mnemonic: "SARVSPST"):

8단계:

  1. Specification — Define functionality, performance, power, area
  2. 사양 — 기능, 성능, 전력, 면적 정의
  3. Architecture — Block diagram, clock domains, pipeline decisions
  4. 아키텍처 — 블록 다이어그램, 클록 도메인, 파이프라인 결정
  5. RTL Design — Write Verilog/SystemVerilog (source code of the chip)
  6. RTL 설계 — Verilog/SystemVerilog 작성
  7. Functional Verification — UVM, constrained random, formal (70% of effort!)
  8. 기능 검증 — UVM, 제약 랜덤, 형식 검증 (노력의 70%!)
  9. Synthesis — RTL → gate-level netlist using standard cell library
  10. 합성 — 표준 셀 라이브러리로 RTL → 게이트 수준 넷리스트
  11. Physical Design (P&R) — Floorplan, placement, CTS, routing
  12. 물리적 설계 (P&R) — 플로어플랜, 배치, CTS, 라우팅
  13. Signoff — STA, DRC/LVS, power analysis, SI
  14. 사인오프 — STA, DRC/LVS, 전력 분석, SI
  15. Fabrication & Test — GDS-II → foundry, ATPG test
  16. 제조 및 테스트 — GDS-II → 파운드리, ATPG 테스트

Key insight: It's iterative, not waterfall. Front-end = logic (1-4), Back-end = physical (5-8).

핵심: 워터폴이 아닌 반복적. 프론트엔드 = 논리 (1-4), 백엔드 = 물리적 (5-8).

3 Synchronous Design vs. Asynchronous Design — differences and trade-offs?동기 설계 vs. 비동기 설계 — 차이점과 트레이드오프?

Synchronous: Global clock, all state changes on clock edges. Predictable, STA-friendly, testable (scan chains). 99% of industry.

동기: 글로벌 클록, 모든 상태 변화가 클록 에지에서. 예측 가능, STA 친화적, 테스트 가능. 업계 99%.

Asynchronous: Handshaking, no global clock. Lower power (no clock tree), but very hard to verify and time. Limited EDA tool support.

비동기: 핸드셰이킹, 글로벌 클록 없음. 낮은 전력이지만 검증과 타이밍이 매우 어려움.

Follow-up buzzwords: Clock domain crossing Metastability 2-FF synchronizer Clock gating

Section 2: FSM & Memory섹션 2: FSM & 메모리

4 What is an FSM? Explain Moore vs Mealy.FSM이란? Moore vs Mealy 설명.

FSM = Finite State Machine: sequential circuit with finite states, transitions based on inputs, outputs based on state.

FSM = 유한 상태 기계: 유한한 상태, 입력 기반 전이, 상태 기반 출력을 가진 순차 회로.

Moore: Output depends ONLY on current state. More states needed, but glitch-free outputs (registered). Mealy: Output depends on state AND inputs. Fewer states, responds one cycle faster, but outputs can glitch.

Moore: 출력이 현재 상태에만 의존. 더 많은 상태 필요, 글리치 없는 출력. Mealy: 출력이 상태와 입력에 의존. 더 적은 상태, 한 사이클 빠른 응답.

Components: State register (FFs), next-state logic (combinational), output logic. Encoding: Binary (log₂N FFs), One-hot (N FFs, faster decode).

구성요소: 상태 레지스터 (FF), 다음 상태 논리, 출력 논리. 인코딩: 이진 (log₂N FF), 원-핫 (N FF).

🧠 "Moore = More states, Mealy = iMMediate response"

5a What are the architectural components of a controller?컨트롤러의 아키텍처 구성 요소는?

Three parts: (1) Datapath — registers, ALU, muxes (does computation). (2) Control unit — FSM generating control signals. (3) Memory — stores data/instructions.

세 부분: (1) 데이터패스 — 레지스터, ALU, 먹스 (계산). (2) 제어 유닛 — 제어 신호 생성 FSM. (3) 메모리 — 데이터/명령어 저장.

Datapath Control unit ALU Register file

5b What is non-volatile memory?비휘발성 메모리란?

Memory that retains data when power is off. Examples: Flash (NAND/NOR), ROM, EEPROM, MRAM. Key mechanism: trapped charge on floating gate (Flash) or programmed connections (ROM).

전원이 꺼져도 데이터를 유지하는 메모리. 예: Flash, ROM, EEPROM, MRAM.

5c Flash Memory vs RAM vs ROM — key differences?플래시 메모리 vs RAM vs ROM — 핵심 차이?

FeatureFlashRAMROM
Volatile?NoYesNo
Writable?Yes (block erase)Yes (byte-level)No

Endurance~10K-100K cyclesUnlimitedN/A

SRAM: 6T, fast, expensive → caches. DRAM: 1T1C, dense, needs refresh → main memory.

SRAM: 6T, 빠름, 비쌈 → 캐시. DRAM: 1T1C, 고밀도, 리프레시 필요 → 메인 메모리.

5d Op-Amp vs Comparator — what's the difference?오피앰프 vs 비교기 — 차이점?

Op-Amp: Closed-loop (with feedback), analog output, compensated for stability, slower. Comparator: Open-loop, digital output (slams to VDD/GND), no compensation, faster.

오피앰프: 폐루프, 아날로그 출력, 안정성 보상, 느림. 비교기: 개방 루프, 디지털 출력, 보상 없음, 빠름.

⚠️ Never use op-amp as comparator (slow slew, may latch up). Never use comparator with feedback (no compensation, will ring).

Section 3: Digital Building Blocks섹션 3: 디지털 기본 블록

6a What's the difference between a latch and a flip-flop?래치와 플립플롭의 차이는?

Latch: Level-sensitive, transparent when enable is active. Flip-flop: Edge-triggered, captures only at clock edge. A D-FF = two latches in series (master-slave).

래치: 레벨 감지, 인에이블 활성 시 투명. 플립플롭: 에지 트리거, 클록 에지에서만 캡처.

🧠 "Latch = Level, FF = eFfedge". FFs preferred in sync design for clean timing analysis. Latches used for time borrowing in high-perf designs.

6b Sequential vs combinational circuits?순차 vs 조합 회로?

Combinational: Output = f(current inputs only). No memory. Examples: adder, mux, decoder.

조합: 출력 = f(현재 입력만). 메모리 없음. 예: 가산기, 먹스, 디코더.

Sequential: Output = f(current inputs + stored state). Has memory elements (FFs/latches). Examples: counter, FSM, shift register.

순차: 출력 = f(현재 입력 + 저장 상태). 메모리 요소 있음. 예: 카운터, FSM, 시프트 레지스터.

6c What is a race condition? What is a timing loop?레이스 컨디션이란? 타이밍 루프란?

Race condition: Two signals compete to arrive at the same point; outcome depends on which arrives first — nondeterministic. Can happen even in well-structured circuits.

레이스 컨디션: 두 신호가 경쟁하여 결과가 도착 순서에 따라 달라짐.

Timing loop: Signal feeds back through purely combinational logic with NO register. Structural bug → oscillation. Fix: insert a register to break the loop.

타이밍 루프: 레지스터 없이 순수 조합 논리를 통해 신호가 피드백. 구조적 버그.

⚠️ Race = timing issue. Loop = structural bug. Different problems, different fixes.

7 Minimum D flip-flops for 7-state FSM? With one-hot encoding?7상태 FSM의 최소 D 플립플롭 수? 원-핫 인코딩은?

Binary: ⌈log₂(7)⌉ = 3 FFs (3 bits → 8 states ≥ 7). One-hot: 7 FFs (one per state).

이진: ⌈log₂(7)⌉ = 3 FF. 원-핫: 7 FF.

Trade-off: Binary = fewer FFs, complex decode. One-hot = more FFs, simpler/faster logic. One-hot preferred in FPGAs (abundant FFs), binary in ASICs (area).

트레이드오프: 이진 = 적은 FF, 복잡한 디코드. 원-핫 = 많은 FF, 간단/빠른 논리.

Section 4: Timing섹션 4: 타이밍

8a What are setup time and hold time?셋업 타임과 홀드 타임이란?

Setup (Tsu): Min time data must be stable BEFORE clock edge. Hold (Th): Min time data must be stable AFTER clock edge.

셋업: 클록 에지 전 데이터 안정 최소 시간. 홀드: 클록 에지 후 데이터 안정 최소 시간.

Equations: Setup: Tclk > Tcq + Tcomb + Tsu. Hold: Tcq + Tcomb > Th.

🧠 "Setup = data arrives early enough. Hold = data stays long enough."

8b Three methods to fix a setup violation?셋업 위반 해결 세 가지 방법?

Setup = data too LATE. Fixes: (1) Reduce combinational delay (faster cells LVT, logic optimization). (2) Increase clock period (reduce freq — last resort). (3) Pipeline the path (insert registers).

(1) 조합 지연 감소 (빠른 셀, 논리 최적화). (2) 클록 주기 증가 (최후 수단). (3) 파이프라이닝.

Also: upsize cells, useful skew, buffering.

8c Three methods to fix a hold violation?홀드 위반 해결 세 가지 방법?

Hold = data changes too FAST. Fixes: (1) Add delay buffers. (2) Use slower cells (HVT). (3) Adjust clock skew (delay capture clock).

(1) 지연 버퍼 추가. (2) 더 느린 셀 (HVT). (3) 클록 스큐 조정.

⚠️ CRITICAL: Hold violations can't be fixed by slowing the clock! More dangerous than setup violations. Must be fixed structurally.

8d List methods to improve circuit speed.회로 속도 개선 방법을 나열하세요.

Group in 3 levels: Architecture: Pipeline, parallelism. Logic: Faster cells (LVT), upsize, logic restructuring (balanced trees), reduce fan-out. Physical: Better placement, shorter wires, wider metal, clock skew optimization, increase VDD.

3단계: 아키텍처: 파이프라인. 논리: 빠른 셀, 업사이징, 논리 재구성. 물리적: 배치 최적화, 짧은 와이어, VDD 증가.

Section 5: Verilog섹션 5: Verilog

9a Blocking vs Non-blocking in Verilog?Verilog에서 블로킹 vs 논블로킹?

Blocking (=): Sequential execution. Each statement finishes before next starts. Use for combinational logic (always @(*)).

블로킹 (=): 순차 실행. 조합 논리에 사용.

Non-blocking (<=): Concurrent. All RHS evaluated first, all LHS updated at end of timestep. Use for sequential logic (always @(posedge clk)).

논블로킹 (<=): 동시. 순차 논리에 사용.

⚠️ Rule is absolute: = for combinational, <= for sequential. Mixing = #1 Verilog bug.

9b Verilog task vs function?Verilog 태스크 vs 함수?

Function: No delays, returns one value, input-only, calls only functions, always synthesizable. Task: Can have delays (#, @, wait), no return (uses output args), input/output/inout, can call tasks, synthesizable only if no timing.

함수: 지연 없음, 하나의 값 반환, 입력만, 항상 합성 가능. 태스크: 지연 가능, 반환 없음 (출력 인수), I/O 가능.

Quick: "Function = pure computation. Task = more flexible (delays, multiple outputs)."

9c How many patterns for exhaustive testing of a combinational circuit with 7 inputs and 3 outputs?7입력 3출력 조합 회로의 완전 테스트 패턴 수?

2⁷ = 128 patterns. Outputs don't matter — exhaustive testing covers all INPUT combinations. Each input combo produces a fixed output (combinational = no state). You check 3 output values per pattern.

2⁷ = 128 패턴. 출력 수는 관계없음 — 모든 입력 조합을 커버.

Section 6: Transistor Physics섹션 6: 트랜지스터 물리학

10a What are the operating regions of a MOSFET?MOSFET의 동작 영역은?

Three regions: (1) Cutoff (VGS < Vth): OFF, ID=0. (2) Linear/Triode (VDS < Vov): variable resistor. (3) Saturation (VDS ≥ Vov): current source, ID ∝ (VGS-Vth)².

세 영역: (1) 차단: OFF. (2) 선형: 가변 저항. (3) 포화: 전류원.

🧠 "Cut-Lin-Sat: OFF → Resistor → Current source"

10b Write the ID equation for each MOSFET region.각 MOSFET 영역의 ID 방정식을 쓰세요.

Cutoff: ID = 0

Linear: ID = μnCox(W/L)[(VGS-Vth)VDS - VDS²/2]

Saturation: ID = (μnCox/2)(W/L)(VGS-Vth)²(1+λVDS)

Don't just recite — say: "In saturation, current is proportional to the SQUARE of the overdrive voltage. In linear, it's roughly proportional to VDS."

10c Why does CMOS use both p & n transistors?CMOS가 p & n 트랜지스터를 모두 사용하는 이유?

Rail-to-rail output + zero static power. PMOS pulls to VDD (strong 1), NMOS pulls to GND (strong 0). Only one network conducts at a time → no DC path from VDD to GND. NMOS alone: passes weak 1. PMOS alone: passes weak 0. Together: full swing, no static current, high noise margins.

레일-투-레일 출력 + 제로 정적 전력. PMOS는 VDD로 풀업 (강한 1), NMOS는 GND로 풀다운 (강한 0).

10d Effect of supply voltage and temperature on performance?공급 전압과 온도가 성능에 미치는 영향?

↑ VDD: ↑ speed, ↑ dynamic power (P∝CV²f), ↑ noise margin. ↓ VDD: opposite + more Vth sensitivity.

↑ Temp: ↓ mobility → slower. ↓ Vth (slightly) → ↑ leakage. ↑ wire resistance → more IR drop.

↑ VDD: ↑ 속도, ↑ 전력. ↑ 온도: ↓ 이동도 → 느려짐, ↑ 누설.

🎤 Mention PVT corners: worst speed = slow process, low voltage, high temp.

10e What is threshold voltage and the body effect?문턱 전압과 바디 효과란?

Vth: Minimum VGS to create conducting channel. Body effect: Vth increases when VSB ≠ 0 (body acts as second gate). Vth = Vth0 + γ(√(2φf+VSB) - √(2φf)).

Vth: 전도 채널 생성에 필요한 최소 VGS. 바디 효과: VSB ≠ 0일 때 Vth 증가.

Practical: In stacked NMOS (NAND), upper transistor has VSB > 0 → higher Vth → slower. This is why deep stacks are avoided.

Section 7: Advanced CMOS Effects섹션 7: 고급 CMOS 효과

11a What is channel length modulation?채널 길이 변조란?

In saturation, increasing VDS pushes pinch-off point toward source → effectively shortens channel → more current. Modeled by (1+λVDS). λ ∝ 1/L. Means output resistance is finite: ro = 1/(λID). Limits amplifier gain. Use longer channels to reduce.

포화에서 VDS 증가 → 핀치오프 포인트가 소스 쪽으로 이동 → 채널 단축 → 전류 증가. (1+λVDS)로 모델링.

11b What is charge sharing?전하 공유란?

In dynamic logic/DRAM: precharged node connects to uncharged parasitic capacitance → charge redistributes → voltage drops unexpectedly. Vfinal = (C₁V₁+C₂V₂)/(C₁+C₂). Can cause wrong logic value. Fix: precharge internal nodes or use keeper transistors.

동적 논리/DRAM에서: 프리차지된 노드가 미충전 기생 커패시턴스에 연결 → 전하 재분배 → 전압 하락.

11c What is electromigration and how to prevent it?일렉트로마이그레이션이란, 예방 방법은?

Physical movement of metal atoms due to high current density. Creates voids (opens) and hillocks (shorts). Reliability failure.

높은 전류 밀도로 인한 금속 원자의 물리적 이동. 보이드(개방)와 힐록(단락) 생성.

Prevention: (1) Wider wires. (2) Copper (better than Al). (3) Redundant vias. (4) Limit current density (EDA checks). (5) Lower temperature (Arrhenius).

Electromigration Current density Black's equation MTTF

Section 8: Capacitors & Latch-up섹션 8: 커패시터 & 래치업

12a Name three basic types of capacitors in CMOS design.CMOS 설계의 세 가지 기본 커패시터 유형은?

(1) Gate capacitance (Cox) — gate to channel. (2) Diffusion/Junction (Cj) — PN junction at S/D. (3) Overlap/Fringing (Cov) — gate-to-S/D overlap.

(1) 게이트 커패시턴스 — 게이트-채널. (2) 확산/접합 — S/D의 PN 접합. (3) 오버랩/프린징 — 게이트-S/D 오버랩.

12b List the three capacitors in order of consideration (largest impact first).세 커패시터를 고려 순서(영향 큰 순)로 나열하세요.

1. Cox (gate) — dominates, determines speed/power. 2. Cj (diffusion) — significant in submicron. 3. Cov (overlap) — causes Miller effect (Cgd × gain).

1. Cox → 2. Cj → 3. Cov

Note: In modern nodes, wire capacitance often dominates over device capacitance!

12c What is latch-up and how to prevent it?래치업이란, 예방 방법은?

Parasitic SCR (thyristor) triggering in CMOS. PNPN structure forms two parasitic BJTs in positive feedback loop. Once triggered → low-impedance VDD-to-GND short → massive current → chip destruction.

CMOS에서 기생 SCR 트리거링. PNPN 구조가 양성 피드백 루프 형성.

Prevention: (1) Guard rings (N+ around NMOS, P+ around PMOS). (2) More substrate/well contacts (reduce parasitic R). (3) Increase NMOS-PMOS spacing. (4) EPI substrate. (5) SOI (eliminates PNPN entirely).

13b Draw a 2-input XOR using only NAND gates. How many NANDs?NAND 게이트만 사용한 2입력 XOR을 그리세요. 몇 개의 NAND?

4 NAND gates. Pattern: NAND1 = A NAND B. NAND2 = A NAND (NAND1). NAND3 = B NAND (NAND1). NAND4 = NAND2 NAND NAND3 = output.

4개 NAND 게이트.

🎤 "First NAND the two inputs. Then NAND each original input with that result. Finally NAND those two results." NAND is universal — any function from NANDs alone.

13c How to design a divide-by-3 counter with 50% duty cycle?50% 듀티 사이클의 3분주 카운터 설계 방법?

Use two mod-3 counters: one on posedge, one on negedge. Each generates a 1-cycle pulse every 3 cycles. OR their outputs → 50% duty cycle. Key insight: odd dividers need both clock edges for 50% duty cycle.

두 개의 mod-3 카운터 사용: posedge와 negedge. 출력을 OR하면 50% 듀티 사이클.

Section 10: Verilog Design섹션 10: Verilog 설계

14a Write Verilog for a clock (50ns period) and 5-bit counter.클록 (50ns 주기)과 5비트 카운터의 Verilog를 작성하세요.

// Clock: 50ns period = toggle every 25ns
initial clk = 0;
always #25 clk = ~clk;

// 5-bit counter (0-31, wraps)
always @(posedge clk or posedge rst)
  if (rst) count <= 5'b0;
  else     count <= count + 1;

Key: Clock gen is testbench-only (uses #delay, not synthesizable). Counter uses async reset.

14b Write Verilog for parallel-to-serial conversion of a 5-bit counter.5비트 카운터의 병렬-직렬 변환 Verilog를 작성하세요.

Load 5 bits in parallel, shift out MSB-first one bit per clock:

assign ser_out = shift_reg[4]; // MSB first
always @(posedge clk)
  if (load) shift_reg <= par_in;
  else     shift_reg <= {shift_reg[3:0], 1'b0};

Key concept: load all bits at once, shift out one per clock.

14c Design a sequence detect circuit that counts to 25.25까지 카운트하는 시퀀스 검출 회로를 설계하세요.

always @(posedge clk or posedge rst)
  if (rst) {count,detect} <= 0;
  else if (count == 5'd24)
    {count,detect} <= {5'b0, 1'b1};
  else
    {count,detect} <= {count+1, 1'b0};

Compare against 24 (not 25) because counting starts from 0. 0→24 = 25 counts.

Section 11: Layout섹션 11: 레이아웃

15a Draw the transistor schematic of a CMOS NOR gate.CMOS NOR 게이트의 트랜지스터 회로도를 그리세요.

PMOS in SERIES (pull-up): Both P1(A) and P2(B) must be ON to pull high → both inputs must be 0. NMOS in PARALLEL (pull-down): Either N1(A) or N2(B) pulls low → if either input is 1, output is 0.

PMOS 직렬 (풀업), NMOS 병렬 (풀다운).

🧠 "NOR: NMOS parallel, PMOS series. NAND: opposite." PMOS is 2-3x wider than NMOS (hole mobility lower).

15b Draw the layout (stick diagram) and cross-section of a NOR gate.NOR 게이트의 레이아웃(스틱 다이어그램)과 단면도를 그리세요.

Layout rules: VDD on top, GND on bottom. PMOS in n-well (top), NMOS in p-sub (bottom). Poly gates run vertically across both regions. Power rails horizontal metal.

레이아웃 규칙: VDD 위, GND 아래. PMOS는 n-웰(위), NMOS는 p-기판(아래).

Cross-section shows: p-substrate base, n-well for PMOS, gate oxide, polysilicon gates, metal contacts, S/D diffusions. PMOS has p+ diffusions in n-well. NMOS has n+ diffusions in p-substrate.

Series PMOS share diffusion (saves area). Parallel NMOS each connect to output and GND independently.

Section 12: Static Timing Analysis섹션 12: 정적 타이밍 분석

16a Why specify input and output delays during synthesis?합성 시 입력/출력 지연을 지정하는 이유?

Your block connects to others. Input delay: How much clock period is "used up" before data reaches your input (by external logic). Output delay: How much time the downstream block needs after your output. Without these → tool assumes infinite budget at I/O → timing fails during integration.

입력 지연: 외부 논리에 의해 데이터가 입력에 도달하기 전 사용된 시간. 출력 지연: 다운스트림 블록이 필요한 시간.

Example: 10ns clock, 3ns input delay, 2ns output delay → internal budget = 5ns.

set_input_delay set_output_delay SDC

16b Propagated clock vs ideal clock in timing reports?타이밍 보고서에서 전파 클록 vs 이상 클록?

Ideal clock: Zero skew, zero latency. Simplification for synthesis (pre-CTS). Propagated clock: Models actual clock tree — real insertion delay, skew, jitter. Used post-CTS for signoff.

이상 클록: 제로 스큐/레이턴시 (합성용). 전파 클록: 실제 클록 트리 모델링 (사인오프용).

Propagated can reveal new violations AND fix some (useful skew). Used ideal early, switch to propagated after CTS.

16c What is time borrowing in STA (PrimeTime)?PrimeTime에서 STA의 타임 보로잉이란?

Latch-based design technique. Since latches are transparent when enabled, late-arriving data can still pass through — "borrowing" time from the next stage. One stage can exceed its clock budget if the next stage has slack. FF-based designs can't borrow (data MUST arrive before edge).

래치 기반 설계 기법. 래치가 투명할 때 늦게 도착한 데이터도 통과 가능 — 다음 단계에서 시간을 "빌림".

Limit: borrow up to transparent window minus setup time. PrimeTime auto-calculates. Used in high-perf CPUs (Intel, ARM). Downside: complex STA, can cascade.
