Exercise 1: Build an N-bit Adder 연습 1: N비트 가산기 만들기

📋 What You'll Build

📋 만들 것

A simple adder that adds two numbers together. The cool part: you can make it work for any bit width using parameters!

두 숫자를 더하는 간단한 가산기. 멋진 점: 파라미터를 사용해서 어떤 비트 너비에서도 작동하게 만들 수 있습니다!

📝 Requirements

📝 요구사항

  • Module name: adder
  • 모듈 이름: adder
  • Parameter: WIDTH (default = 8)
  • 파라미터: WIDTH (기본값 = 8)
  • Inputs: a, b (WIDTH bits each), cin (1 bit)
  • 입력: a, b (각 WIDTH 비트), cin (1비트)
  • Outputs: sum (WIDTH bits), cout (1 bit)
  • 출력: sum (WIDTH 비트), cout (1비트)

🚀 Step-by-Step Instructions

🚀 단계별 지침

Step 1:1단계: Start with the module declaration and parameter: 모듈 선언과 파라미터로 시작:

module adder #( parameter int WIDTH = 8 )( // Ports go here... );

Step 2:2단계: Add the input ports. Remember to use [WIDTH-1:0] for the bit range: 입력 포트 추가. 비트 범위에 [WIDTH-1:0] 사용 기억:

input logic [WIDTH-1:0] a, input logic [WIDTH-1:0] b, input logic cin,

Step 3:3단계: Add the output ports: 출력 포트 추가:

output logic [WIDTH-1:0] sum, output logic cout

Step 4:4단계: Add the logic! The trick: use {cout, sum} to capture the full result: 로직 추가! 비결: {cout, sum}으로 전체 결과 캡처:

assign {cout, sum} = a + b + cin;

✅ Test Your Module

✅ 모듈 테스트

🔍 See Complete Solution 🔍 전체 정답 보기

Design Code (Right Panel in EDA Playground):

설계 코드 (EDA Playground 오른쪽 패널):

module adder #( parameter int WIDTH = 8 )( input logic [WIDTH-1:0] a, input logic [WIDTH-1:0] b, input logic cin, output logic [WIDTH-1:0] sum, output logic cout ); // Add and capture carry in cout assign {cout, sum} = a + b + cin; endmodule

Testbench Code (Left Panel in EDA Playground):

테스트벤치 코드 (EDA Playground 왼쪽 패널):

module adder_tb; // Test signals logic [7:0] a, b; logic cin; logic [7:0] sum; logic cout; // Connect to the adder adder #(.WIDTH(8)) dut ( .a(a), .b(b), .cin(cin), .sum(sum), .cout(cout) ); // Generate waveforms initial begin $dumpfile("dump.vcd"); $dumpvars; end // Run tests initial begin // Test 1: 0 + 0 a = 8'h00; b = 8'h00; cin = 0; #10; $display("Test 1: %h + %h = %h, cout=%b", a, b, sum, cout); // Test 2: 0F + 01 = 10 a = 8'h0F; b = 8'h01; cin = 0; #10; $display("Test 2: %h + %h = %h, cout=%b", a, b, sum, cout); // Test 3: FF + 01 = 00 with overflow a = 8'hFF; b = 8'h01; cin = 0; #10; $display("Test 3: %h + %h = %h, cout=%b", a, b, sum, cout); $display("All tests done!"); $finish; end endmodule

Exercise 2: Build a 4:1 Multiplexer 연습 2: 4대1 멀티플렉서 만들기

📋 What You'll Build

📋 만들 것

A multiplexer (MUX) selects one of several inputs based on a select signal. Think of it like a TV remote - you press a button to choose which channel to watch!

멀티플렉서(MUX)는 선택 신호를 기반으로 여러 입력 중 하나를 선택합니다. TV 리모컨처럼 생각하세요 - 버튼을 눌러 어떤 채널을 볼지 선택합니다!

📝 Requirements

📝 요구사항

  • Module name: mux4
  • 모듈 이름: mux4
  • Inputs: in0, in1, in2, in3 (8 bits each)
  • 입력: in0, in1, in2, in3 (각 8비트)
  • Select: sel (2 bits)
  • 선택: sel (2비트)
  • Output: out (8 bits)
  • 출력: out (8비트)

🚀 Step-by-Step Instructions

🚀 단계별 지침

Step 1:1단계: Create the module with all ports: 모든 포트로 모듈 생성:

module mux4 ( input logic [7:0] in0, in1, in2, in3, input logic [1:0] sel, output logic [7:0] out );

Step 2:2단계: Use always_comb with a case statement. This is the cleanest way! always_comb과 case 문 사용. 가장 깔끔한 방법입니다!

always_comb begin case (sel) 2'b00: out = in0; 2'b01: out = in1; // Add the other cases... endcase end

Step 3:3단계: Important! Always add a default case to avoid creating a "latch": 중요! "래치" 생성을 피하기 위해 항상 default 케이스 추가:

default: out = 'x; // Unknown value
🔍 See Complete Solution 🔍 전체 정답 보기
module mux4 ( input logic [7:0] in0, in1, in2, in3, input logic [1:0] sel, output logic [7:0] out ); always_comb begin case (sel) 2'b00: out = in0; 2'b01: out = in1; 2'b10: out = in2; 2'b11: out = in3; default: out = 'x; endcase end endmodule

Exercise 3: Connect Modules Together 연습 3: 모듈 연결하기

📋 What You'll Build

📋 만들 것

A top module that uses your adder from Exercise 1. This teaches you how to instantiate (use) modules inside other modules!

연습 1의 가산기를 사용하는 상위 모듈. 다른 모듈 안에서 모듈을 인스턴스화(사용)하는 방법을 배웁니다!

📝 Requirements

📝 요구사항

  • Create a top module
  • top 모듈 생성
  • Instantiate TWO adders: one 8-bit, one 16-bit
  • 두 개의 가산기 인스턴스화: 하나는 8비트, 하나는 16비트
  • Use named port connections (the safe way!)
  • 이름 기반 포트 연결 사용 (안전한 방법!)

🚀 Step-by-Step Instructions

🚀 단계별 지침

Step 1:1단계: Create the top module with ports for both adders: 두 가산기를 위한 포트가 있는 상위 모듈 생성:

module top ( input logic [7:0] a8, b8, // 8-bit inputs input logic [15:0] a16, b16, // 16-bit inputs output logic [7:0] sum8, output logic [15:0] sum16 );

Step 2:2단계: Instantiate the 8-bit adder (uses default WIDTH=8): 8비트 가산기 인스턴스화 (기본 WIDTH=8 사용):

adder u_adder_8bit ( .a (a8), .b (b8), .cin (1'b0), // No carry in .sum (sum8), .cout () // Leave empty if not used );

Step 3:3단계: Instantiate the 16-bit adder (override WIDTH to 16): 16비트 가산기 인스턴스화 (WIDTH를 16으로 오버라이드):

adder #( .WIDTH(16) ) u_adder_16bit ( .a (a16), .b (b16), .cin (1'b0), .sum (sum16), .cout () );
🔍 See Complete Solution 🔍 전체 정답 보기
module top ( input logic [7:0] a8, b8, input logic [15:0] a16, b16, output logic [7:0] sum8, output logic [15:0] sum16, output logic cout8, output logic cout16 ); // 8-bit adder (default parameters) adder u_adder_8bit ( .a (a8), .b (b8), .cin (1'b0), .sum (sum8), .cout (cout8) ); // 16-bit adder (override WIDTH) adder #( .WIDTH(16) ) u_adder_16bit ( .a (a16), .b (b16), .cin (1'b0), .sum (sum16), .cout (cout16) ); endmodule

🐛 Debug Challenge: Find the Bugs! 🐛 디버그 챌린지: 버그 찾기!

Each of these code snippets has bugs. Can you find and fix them?

각 코드 스니펫에 버그가 있습니다. 찾아서 고칠 수 있나요?

Bug #1: Syntax Errors

버그 #1: 문법 오류

module buggy1 ( input logic [7:0] data_in output logic [7:0] data_out ) assign data_out = data_in; endmodule
🔍 See the Fix 🔍 수정 보기

Bug 1: Missing comma after data_in
Bug 2: Missing semicolon after the port list )

버그 1: data_in 뒤에 쉼표 누락
버그 2: 포트 리스트 ) 뒤에 세미콜론 누락

module fixed1 ( input logic [7:0] data_in, // ← Added comma output logic [7:0] data_out ); // ← Added semicolon assign data_out = data_in; endmodule

Bug #2: Incomplete Case Statement

버그 #2: 불완전한 Case 문

module buggy2 ( input logic [1:0] sel, input logic [7:0] a, b, c, d, output logic [7:0] out ); always_comb begin case (sel) 2'b00: out = a; 2'b01: out = b; 2'b10: out = c; // What about 2'b11? endcase end endmodule
🔍 See the Fix 🔍 수정 보기

Bug: Missing case for 2'b11. This creates an unintended "latch" which is bad for synthesis!

버그: 2'b11 케이스 누락. 이것은 의도치 않은 "래치"를 생성하며 합성에 좋지 않습니다!

always_comb begin case (sel) 2'b00: out = a; 2'b01: out = b; 2'b10: out = c; 2'b11: out = d; // ← Added! default: out = 'x; // ← Good practice! endcase end
