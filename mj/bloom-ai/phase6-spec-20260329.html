1. 📅 Weekly Review System 1. 📅 주간 복습 시스템

🎯 Overview 🎯 개요

An automated weekend review that aggregates everything the user studied during the week — per project. It generates flashcards from weak areas, creates knowledge summaries, visualizes progress, and packages everything into exportable formats (PDF, shareable HTML). 사용자가 한 주 동안 공부한 모든 내용을 프로젝트별로 집계하는 자동 주말 복습 시스템입니다. 취약 분야에서 플래시카드를 생성하고, 지식 요약을 작성하며, 진행 상황을 시각화하고, 모든 것을 내보내기 가능한 형식(PDF, 공유 가능한 HTML)으로 패키징합니다.

📐 Architecture 📐 아키텍처

Data Flow 데이터 흐름

Weekly Cron (Sun 9AM) 주간 크론 (일 오전 9시) → Aggregate week's data 주간 데이터 집계 → AI Analysis (Haiku) AI 분석 (Haiku) → Generate Review Package 복습 패키지 생성 → Push Notification 푸시 알림

What Gets Aggregated (Per Project) 집계 대상 (프로젝트별)

  • Questions answered — total count, correct %, by topic답변한 질문 — 총 개수, 정답률, 주제별
  • Study time — total minutes, by mode, by day학습 시간 — 총 시간(분), 모드별, 일별
  • Topics covered — which ones, depth of coverage다룬 주제 — 어떤 주제를, 얼마나 깊이
  • Weak areas — topics with <70% accuracy or declining trend취약 분야 — 정답률 70% 미만 또는 하락 추세인 주제
  • Breakthrough moments — topics that jumped from weak → strong돌파구 순간 — 취약에서 강점으로 도약한 주제
  • Streak & consistency — daily study streak, missed days연속 학습 & 일관성 — 일일 학습 연속일, 미학습일
  • Mode usage — which study modes used, variety score모드 사용 — 사용한 학습 모드, 다양성 점수
  • SRS data — cards due, cards mastered, retention rateSRS 데이터 — 복습 예정 카드, 마스터 카드, 기억 유지율

class BloomPdfGenerator {
  // Template registry — each content type has its own layout
  static final Map<ExportType, PdfTemplate> templates = {
    ExportType.weeklyReview: WeeklyReviewTemplate(),
    ExportType.flashcards: FlashcardTemplate(),
    ExportType.knowledgeSummary: KnowledgeSummaryTemplate(),
    ExportType.mockExam: MockExamTemplate(),
    ExportType.caseSimulation: CaseSimulationTemplate(),
    ExportType.conceptMap: ConceptMapTemplate(),
    ExportType.progressReport: ProgressReportTemplate(),
    ExportType.studyLog: StudyLogTemplate(),
  };

  Future<File> generate(ExportType type, dynamic data) async {
    final template = templates[type]!;
    final doc = pw.Document();
    
    // Add cover page
    doc.addPage(template.buildCoverPage(data));
    
    // Add content pages
    for (final page in template.buildContentPages(data)) {
      doc.addPage(page);
    }
    
    // Save to device
    final dir = await getApplicationDocumentsDirectory();
    final file = File('${dir.path}/bloom_export_${DateTime.now().millisecondsSinceEpoch}.pdf');
    await file.writeAsBytes(await doc.save());
    return file;
  }
}

3. 🎙️ Voice Mode (OpenAI Realtime API) 3. 🎙️ 음성 모드 (OpenAI 실시간 API)

🎯 Goal 🎯 목표

Lightning-fast, natural voice conversation for studying. Not the old "record → transcribe → send → wait → TTS" pipeline — actual real-time, back-and-forth voice interaction like talking to a tutor sitting next to you. 학습을 위한 초고속, 자연스러운 음성 대화. 기존의 "녹음 → 전사 → 전송 → 대기 → TTS" 파이프라인이 아닌, 옆에 앉아 있는 튜터와 대화하는 것 같은 실시간 양방향 음성 상호작용입니다.

  • Protocol: WebSocket connection to wss://api.openai.com/v1/realtime프로토콜: wss://api.openai.com/v1/realtime로 WebSocket 연결
  • Model: gpt-4o-realtime-preview (speech-to-speech, no intermediate text)모델: gpt-4o-realtime-preview (음성-음성, 중간 텍스트 없음)

  • Transcript: Get text transcripts alongside audio for logging트랜스크립트: 로깅을 위해 오디오와 함께 텍스트 트랜스크립트 수신

// Connection via Supabase Edge Function (secure — no API key on client)
class RealtimeVoiceService {
  WebSocketChannel? _channel;
  final AudioRecorder _recorder;
  final AudioPlayer _player;

  Future<void> connect(String projectId, String sessionContext) async {
    // 1. Get ephemeral token from Edge Function
    final token = await _getEphemeralToken(projectId);
    
    // 2. Connect WebSocket
    _channel = WebSocketChannel.connect(
      Uri.parse('wss://api.openai.com/v1/realtime?model=gpt-4o-realtime-preview'),
      headers: {'Authorization': 'Bearer $token'},
    );
    
    // 3. Send session config with study context
    _channel!.sink.add(jsonEncode({
      'type': 'session.update',
      'session': {
        'instructions': _buildStudyPrompt(sessionContext),
        'voice': 'alloy',
        'input_audio_format': 'pcm16',
        'output_audio_format': 'pcm16',
        'turn_detection': {
          'type': 'server_vad',
          'threshold': 0.5,
          'silence_duration_ms': 500,
        },
        'input_audio_transcription': {'model': 'whisper-1'},
      }
    }));
    
    // 4. Listen for responses
    _channel!.stream.listen(_handleServerEvent);
  }

  void _handleServerEvent(dynamic event) {
    final data = jsonDecode(event);
    switch (data['type']) {
      case 'response.audio.delta':
        // Stream audio chunks to player immediately
        _player.feedAudioChunk(base64Decode(data['delta']));
        break;
      case 'response.audio_transcript.delta':
        // Update live transcript on screen
        _onTranscriptUpdate(data['delta']);
        break;
      case 'input_audio_buffer.speech_started':
        // User started speaking — show visual indicator
        _onUserSpeaking();
        break;
      case 'input_audio_buffer.speech_stopped':
        // User stopped — processing
        _onUserStoppedSpeaking();
        break;
    }
  }
}

SRS Algorithm (SM-2)SRS 알고리즘 (SM-2)

// Spaced Repetition scheduling
class SM2 {
  static SrsState update(SrsState current, int quality) {
    // quality: 0-5 (0=blackout, 5=perfect)
    double ef = current.easeFactor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02));
    ef = max(1.3, ef);
    
    int interval;
    if (quality < 3) {
      interval = 1; // Reset — review tomorrow
    } else if (current.repetitions == 0) {
      interval = 1;
    } else if (current.repetitions == 1) {
      interval = 6;
    } else {
      interval = (current.interval * ef).round();
    }
    
    return SrsState(
      interval: interval,
      easeFactor: ef,
      repetitions: quality < 3 ? 0 : current.repetitions + 1,
      nextReview: DateTime.now().add(Duration(days: interval)),
    );
  }
}

MODE 7 Review & Reflect 복습 & 성찰

Purpose목적

Side-by-side comparison of your past and current answers to the same question. Shows growth over time. Forces metacognition — "What did I know then vs now? What changed?"같은 질문에 대한 과거와 현재 답변의 나란히 비교. 시간에 따른 성장을 보여줍니다. 메타인지를 강제합니다 — "그때 무엇을 알았고 지금은? 무엇이 바뀌었나?"

How It Works작동 방식

  • Question selection: AI picks questions the user answered 2+ weeks ago (prioritizes questions with low initial scores)질문 선택: AI가 2주 이상 전에 답한 질문 선택 (초기 점수가 낮은 질문 우선)
  • Fresh attempt: User answers the question again (without seeing old answer)새로운 시도: 사용자가 다시 답변 (이전 답변을 보지 않고)
  • Comparison view: Split screen — old answer (left, faded) vs new answer (right, highlighted)비교 보기: 분할 화면 — 이전 답변 (왼쪽, 흐릿) vs 새 답변 (오른쪽, 강조)
  • Growth analysis: AI highlights what improved, what regressed, and what's new in the answer성장 분석: AI가 개선된 점, 퇴보한 점, 답변의 새로운 부분을 강조
  • Reflection prompt: "Why do you think your understanding changed?" — optional written reflection saved to memory성찰 프롬프트: "이해가 왜 변했다고 생각하나요?" — 선택적 서면 성찰을 메모리에 저장

Memory Integration메모리 통합

Review & Reflect heavily leverages the Memory Engine — it needs historical answer data, scoring trends, and the ability to identify "growth moments" that are psychologically reinforcing.복습 & 성찰은 메모리 엔진을 집중 활용합니다 — 과거 답변 데이터, 점수 추세, 심리적으로 강화하는 "성장 순간"을 식별하는 능력이 필요합니다.
