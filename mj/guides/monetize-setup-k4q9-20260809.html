Part 1 — App Store Connect (subscriptions)1부 — App Store Connect (구독 만들기)

Skip the "In-App Purchases" page — that's for one-time purchases (the Consumable dialog you saw). Subscriptions live under Monetization → Subscriptions."In-App Purchases" 페이지는 건너뛰세요 — 일회성 구매용입니다(아까 본 Consumable 창). 구독은 Monetization → Subscriptions에 있습니다.
1
ASC → Jujube: Pantry → left sidebar → Monetization → Subscriptions → Create Subscription Group. Reference name: Jujube Pro.ASC → Jujube: Pantry → 왼쪽 메뉴 → Monetization → Subscriptions → Create Subscription Group. 그룹 이름: Jujube Pro.
2
Inside the group → Create Subscription:
Reference Name Pro Monthly · Product ID pro_monthly · Duration 1 Month → after creating, set Price $7.99 USD (Subscription Prices → + → pick $7.99, let Apple auto-set other countries).그룹 안에서 → Create Subscription:
Reference Name Pro Monthly · Product ID pro_monthly · 기간 1 Month → 생성 후 가격 $7.99 USD 설정 (Subscription Prices → + → $7.99 선택, 다른 국가는 자동).
3
Create the second one: Reference Name Pro Annual · Product ID pro_annual · Duration 1 Year → Price $49.99 USD.두 번째 구독 생성: Reference Name Pro Annual · Product ID pro_annual · 기간 1 Year → 가격 $49.99 USD.
4
Free trial (annual only): open pro_annual → Subscription Prices → Introductory Offers → Create → all countries → Start/End: no end date → Type: Free → Duration: 1 week.무료 체험 (연간만): pro_annual 열기 → Subscription Prices → Introductory Offers → Create → 모든 국가 → 종료일 없음 → 유형: Free → 기간: 1 week.
5
For each subscription add a Localization (English at minimum): Display Name e.g. Jujube Pro, Description e.g. Unlimited recipes, receipt scanning, and more. Korean/Chinese optional now. The "review screenshot" can be added later (needed only before App Review).각 구독마다 Localization 추가 (영어 필수): 표시 이름 Jujube Pro, 설명 예: Unlimited recipes, receipt scanning, and more. 한국어/중국어는 나중에 추가 가능. "심사용 스크린샷"은 나중에 추가해도 됩니다 (App 심사 제출 전에만 필요).
6
Paid Apps Agreement (critical!): ASC home → Business (or Agreements, Tax, and Banking) → make sure the Paid Apps agreement is signed and bank + tax info is complete. Subscriptions silently fail without this.유료 앱 계약 (매우 중요!): ASC 홈 → Business (또는 Agreements, Tax, and Banking) → Paid Apps 계약 서명 + 은행/세금 정보 완료 확인. 이거 없으면 구독이 조용히 실패합니다.
7
Copy the App-Specific Shared Secret (RevenueCat needs it): ASC → Jujube app → General → App Information → App-Specific Shared Secret → Manage → generate/copy.App-Specific Shared Secret 복사 (RevenueCat에 필요): ASC → Jujube 앱 → General → App Information → App-Specific Shared Secret → Manage → 생성/복사.

Part 2 — RevenueCat (you're mid-signup here)2부 — RevenueCat (지금 가입 중인 곳)

1
Finish signup (any answers to their onboarding questions are fine — platform: Flutter, store: App Store). Create a Project named Jujube.가입 완료 (온보딩 질문은 아무렇게나 답해도 됨 — 플랫폼: Flutter, 스토어: App Store). Project 이름 Jujube로 생성.
2
Project → Apps → + New App → App Store → App name Jujube, Bundle ID com.fridgenie.app, paste the App-Specific Shared Secret from Part 1 step 7.Project → Apps → + New App → App Store → 앱 이름 Jujube, Bundle ID com.fridgenie.app, 1부 7단계의 Shared Secret 붙여넣기.
3
Entitlements → + New → Identifier: pro (description anything).Entitlements → + New → 식별자: pro (설명은 자유).
4
Products → + New (or Import) → add pro_monthly and pro_annual (App Store). Then open each → attach to the pro entitlement.Products → + New (또는 Import) → pro_monthly, pro_annual 추가 (App Store). 각각 열어서 pro entitlement에 연결.
5
Offerings → open the default offering → add two Packages: Monthly ($rc_monthly) → pro_monthly, and Annual ($rc_annual) → pro_annual.Offerings → default offering 열기 → Packages 2개 추가: Monthly ($rc_monthly) → pro_monthly, Annual ($rc_annual) → pro_annual.
6
API Keys (Project settings → API keys) → copy the Apple public SDK key starting with appl_ → send it to Rex. That's the piece that goes in the app.API Keys (Project settings → API keys) → appl_로 시작하는 Apple public SDK key 복사 → Rex에게 전송. 이 키를 앱에 넣습니다.
Done = two subs live in ASC (trial on annual) + RevenueCat project with pro entitlement, products attached, default offering filled, and the appl_… key sent to Rex. I wire the key, rebuild, and the paywall sells for real (sandbox first).완료 기준: ASC에 구독 2개 (연간에 체험) + RevenueCat에 pro entitlement, 제품 연결, default offering 구성, appl_… 키를 Rex에게 전송. 키를 앱에 넣고 다시 빌드하면 페이월이 실제로 작동합니다 (먼저 샌드박스 테스트).
