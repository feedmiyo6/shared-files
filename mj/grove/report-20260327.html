🌿 What is Grove?Grove란?

Grove is a Personal AI Knowledge Hub — a beautiful Next.js web app for capturing, organizing, and growing your knowledge. Think of it as a second brain with a cozy Ghibli-inspired aesthetic. It features smart capture for links/text/code/ideas, a full markdown notes editor, a focus timer with session tracking, and a knowledge base with powerful filtering. Grove는 개인 AI 지식 허브입니다 — 지식을 캡처하고, 정리하고, 성장시키기 위한 아름다운 Next.js 웹 앱입니다. 아늑한 지브리 스타일의 미학을 가진 세컨드 브레인이라고 생각하세요. 링크/텍스트/코드/아이디어를 위한 스마트 캡처, 마크다운 노트 에디터, 세션 추적이 있는 포커스 타이머, 그리고 강력한 필터링 기능을 갖춘 지식 베이스를 제공합니다.

⚙️ Tech Stack기술 스택

Next.js 14 TypeScript Tailwind CSS shadcn/ui Zustand React Markdown Radix UI Lucide Icons date-fns

Time-based greeting, live Phoenix weather via Open-Meteo API, daily quotes, stats cards, recent activity feed, and GitHub-style activity streak tracker.시간 기반 인사말, Open-Meteo API를 통한 피닉스 실시간 날씨, 오늘의 명언, 통계 카드, 최근 활동 피드, GitHub 스타일 활동 연속 추적기.

Capture links, text, code snippets, and ideas. Tag and categorize everything. Type-specific input (monospace for code). Recent captures sidebar.링크, 텍스트, 코드 스니펫, 아이디어를 캡처. 태그와 카테고리 분류. 유형별 입력 (코드용 고정폭 폰트). 최근 캡처 사이드바.

Grid view with type/category filtering, text search, sort options (newest/oldest/title), expandable cards, color-coded type badges, tag cloud.유형/카테고리 필터링이 있는 그리드 뷰, 텍스트 검색, 정렬 옵션, 확장 가능한 카드, 색상 코딩된 유형 배지, 태그 클라우드.

📝 Notes Editor노트 에디터

Split-pane with note list + editor. Markdown with live preview. Auto-save (1s debounce). Inline title editing. Search across all notes. Tag support.노트 목록 + 에디터 분할 화면. 실시간 미리보기가 있는 마크다운. 자동 저장 (1초 디바운스). 인라인 제목 편집. 전체 노트 검색. 태그 지원.

🎯 Focus Mode포커스 모드

Dark/light/system theme. Profile management. JSON data export/import for backup. Clear all data option. Version info.다크/라이트/시스템 테마. 프로필 관리. 백업용 JSON 데이터 내보내기/가져오기. 전체 데이터 삭제 옵션. 버전 정보.
