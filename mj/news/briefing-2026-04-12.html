Google Releases Gemma 4 — Most Capable Open Models Under Apache 2.0구글 젬마 4 출시 — 아파치 2.0 라이선스 하 최고 성능 오픈 모델

Google / Engadget

Google released Gemma 4, a family of open-weight models from 2B to 31B parameters, built from the same research as Gemini 3. The flagship 31B model handles 256K context windows, native vision and audio, 140+ languages, and built-in function calling. A major shift: it's now under a commercially permissive Apache 2.0 license, with over 400 million downloads to date.구글이 2B~31B 파라미터의 오픈 웨이트 모델군 젬마 4를 출시했습니다. 제미나이 3과 동일한 연구 기반으로 구축된 플래그십 31B 모델은 256K 컨텍스트 윈도우, 네이티브 비전·오디오, 140개 이상 언어를 지원합니다. 상용 허용 아파치 2.0 라이선스로 전환된 것이 큰 변화이며, 누적 다운로드는 4억 회를 넘었습니다.

The Hacker News / BleepingComputer

CVE-2026-39987, a pre-auth remote code execution flaw in the popular Python notebook tool Marimo (CVSS 9.3), was exploited just 10 hours after disclosure. Attackers built a working exploit directly from the advisory, gaining root shell access. Default Docker images run as root, making the impact severe. Users should upgrade to v0.23.0 immediately.인기 파이썬 노트북 도구 마리모의 사전 인증 원격 코드 실행 취약점 CVE-2026-39987(CVSS 9.3)이 공개 10시간 만에 악용되었습니다. 공격자가 권고문만으로 익스플로잇을 제작해 루트 쉘 접근을 획득했으며, 기본 도커 이미지가 루트로 실행되어 피해가 심각합니다. v0.23.0으로 즉시 업그레이드가 필요합니다.
